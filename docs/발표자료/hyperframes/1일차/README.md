# 1일차 발표 덱 — hyperframes 판

실습 한 장을 **한 단계씩 공개**하고, 강사 화면에 **발표자 노트 · 다음 장 · 경과 시간**을 띄우는 판이다. 장 구성 · 문구 · 디자인은 `../../1일차.html` 과 같다(그 파일은 그대로 있고, 파일로 열기 · 인쇄는 그쪽에서 한다).

## 여는 법

```
cd docs/발표자료/hyperframes/1일차
hyperframes present .
```

주소(기본 `http://localhost:3004`)가 브라우저에 열린다. **P** 를 누르면 투사용 청중 탭이 새로 열리고, 지금 탭은 발표자 화면이 된다. 청중 탭을 프로젝터 화면으로 옮겨 전체화면으로 둔다. 글꼴과 GSAP는 이 폴더 안에 있어 인터넷 없이도 열린다.

| 키 | 하는 일 |
|---|---|
| → · Space | 다음 단계 (마지막 단계 다음은 다음 장) |
| ← · Backspace | **이전 장**으로 (그 장의 처음 상태 — 같은 장 안에서 한 단계 되돌리기는 안 된다) |
| P | 발표자 모드 |

- 한 장은 □ 단계(와 그 ○ 입력 표)가 한 묶음씩 나온다. 새 묶음이 나오면 앞 묶음은 흐려지고, 마지막 누름('완료 기준')에서 전부 진하게 돌아온다.
- 단계 사이 이동은 건너뛰기다. 움직임(애니메이션)은 보이지 않는다.
- 지난 장의 명령을 다시 보여 줄 때는 ← 로 간 뒤 → 로 끝까지 누른다.

## 고칠 때

| 하고 싶은 것 | 어디를 |
|---|---|
| 장 문구 | `compositions/sNN-*.html` (마크업 그대로) |
| 공개 순서 | 각 파일 맨 아래 `hfReveal("장이름", [[묶음1 선택자], [묶음2 선택자], …])` |
| 발표자 노트 | `index.html` 맨 위 JSON 의 `notes` |
| 글자 · 표 모양 | `deck.css` |

묶음 수를 바꾸면 `index.html` 도 맞춘다. 묶음 k(0부터)에서 멈추는 시각은 **장 시작 시각 + k + 1**(`fragments`), 장 길이(`data-duration`)는 **묶음 수 + 1**, 뒤 장의 `data-start` 는 그만큼 밀린다. 고친 뒤 확인:

```
hyperframes lint .
hyperframes check .
```

## 확인하지 못한 것

Windows · 실제 프로젝터에서의 보임, 이 폴더를 `hyperframes present` 로 여는 강사 PC(Windows면 설치 방법)는 확인하지 못했다. 글꼴은 OFL(`fonts/OFL-*.txt`), `vendor/gsap.min.js` 는 GSAP 표준 무료 라이선스(https://gsap.com/standard-license)다.
