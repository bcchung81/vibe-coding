## 단계
공개 hwpx의 표를 추출하고, 표마다 한 줄 요약을 붙여 tables.md로 저장한다.
## 확인 기준
원문의 표 개수와 결과의 표 개수를 대조하고 누락 여부를 알린다.
## 하지 말 것
원본을 수정하거나 원문에 없는 수치를 만들지 않는다.
  • 위치: my-weekly-table\SKILL.md — 폴더 하나 + 파일 하나
  • name 은 영문 소문자 · - / description = 언제 불릴지 — 넓으면 엉뚱하게, 좁으면 안 불린다
