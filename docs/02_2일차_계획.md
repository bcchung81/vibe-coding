## 4교시 · 나만의 업무 명령 만들기 (15:10–16:20)

**목표**: 오늘 해 본 일이나 내 업무에서 반복되는 절차 하나를 스킬(`SKILL.md`)로 만들어, 새 대화에서 한 줄로 다시 부른다. (과정 목표 4)

| 시간 | 진행 |
|---|---|
| 15:10–15:20 | 강의 — 스킬은 절차를 적은 파일 하나 |
| 15:20–16:05 | 실습 — 재료 고르기 → 인터뷰로 `SKILL.md` → 새 대화에서 불러 보기 → 한 번 고치기 |
| 16:05–16:20 | 정리 — 좋은 명령의 조건 · 남이 만든 스킬 쓰기 |

### 강의 (10분)

- **스킬 = 폴더 하나 + `SKILL.md`**. 맨 위에 `name`(영문 소문자 · `-`) · `description`, 아래에 단계 · 확인 기준 · 하지 말 것.
- **description이 "언제 불릴지"를 정한다**: 에이전트는 목록에서 description만 보고 고른다. "보고서" 처럼 넓으면 엉뚱한 때 불리고, 너무 좁으면 안 불린다.
- **실례** (강사 화면): 오전에 쓴 `think` 의 `SKILL.md` 를 연다. 3교시 보고서 도구도 같은 구조의 파일 묶음이다.
- **어디에 두나**: 전역 스킬 폴더에 두면 어느 폴더에서든 부른다. `setup.ps1` 이 `think` 를 둔 곳과 같다.

| 에이전트 | 전역 스킬 폴더 | 부르는 법 |
|---|---|---|
| Codex | `~\.agents\skills\<이름>\SKILL.md` | `<이름> 스킬로 ~해줘` |
| Claude Code | `~\.claude\skills\<이름>\SKILL.md` | `/<이름>` |
| Antigravity | `~\.gemini\config\skills\<이름>\SKILL.md` | `<이름> 스킬로 ~해줘` |

### 실습 (45분)

1. **재료 고르기** (5분) — 2교시에 적은 한 줄, 3교시 보고서 단계, 사전과제 메모 중 매주 · 매달 하는 일 하나. 예: 매주 받는 hwpx 표를 요약표로 · 개정 법령 조문 찾아 정리 · CSV 월별 집계 · 보고서 서술 문단 다듬기.
2. **인터뷰로 만들기** (20분)
   ```
   내가 반복하는 업무를 스킬로 만들고 싶어. 질문을 하나씩, 5개 이하로 해서 입력 · 결과물 · 확인 기준 · 하지 말 것을 정해 줘. 다 정해지면 내 에이전트의 전역 스킬 폴더에 <이름>/SKILL.md 로 저장하고 파일 내용을 보여줘
   ```
   - 2교시처럼 MCP가 필요한 일이면 "kordoc MCP로 표를 읽는다"처럼 쓸 도구를 단계에 적게 한다.
3. **새 대화에서 불러 보기** (10분) — 에이전트를 닫고 다시 연다 → 스킬 목록에 보이는지 확인(`/skills`) → 한 줄로 부른다. 입력 파일이 필요하면 2교시 · 3교시 자료를 쓴다.
4. **한 번 고치기** (10분) — 결과가 기대와 다르면 `SKILL.md 의 확인 기준을 ~로 바꿔줘` → 새 대화에서 다시 부른다.

**자주 막히는 곳 → 조교 대응**

| 증상 | 원인 | 대응 |
|---|---|---|
| 새 대화에서 스킬이 안 보인다 | 저장 위치가 전역 폴더가 아니거나 에이전트를 다시 열지 않음 | 위 표의 폴더에 있는지 확인 → 에이전트를 다시 연다 |
| 이름을 불러도 다른 스킬이 돈다 | 이름이 기존 스킬과 겹침 | 내 이름 앞에 짧은 머리말을 붙인다 (예: `my-weekly-table`) |
| 결과가 매번 다르다 | 결과 파일 이름 · 형식이 안 정해짐 | `SKILL.md` 에 결과 파일 이름과 표 형식을 못 박는다 |
