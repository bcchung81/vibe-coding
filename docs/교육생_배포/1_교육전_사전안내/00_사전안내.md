### 2-1. 코드 에이전트 — 기관 지원 (미리 할 것 없음)

- 교육은 OpenAI의 코드 에이전트 **Codex** 로 한다. Codex(ChatGPT) 계정은 기관이 지원하므로 따로 구독 · 결제하지 않는다.
- 계정은 **교육 당일** 받고, 1교시에 그 계정으로 로그인한다. 받는 방법은 강사가 당일 안내한다.
- **API 키 로그인과 추가 결제(크레딧)는 켜지 않는다.** 사용량만큼 요금이 따로 나간다.
- 지원 계정에도 **사용 한도**(5시간 · 주간)가 있고, 복잡한 요청일수록 빨리 찬다.

### 2-2. 계정 · API 신청

| | 신청할 것 | 사이트 | 받은 값 확인 위치 | `setup.ps1` 에서 |
|---|---|---|---|---|
| ① | Codex 계정(기관 지원, 당일 받음) | 신청하지 않는다 (2-1) | 교육 당일 `codex login status` | 로그인하지 않는다 — 결과에 `SKIP` |
| ② | GitHub 계정 | https://github.com/signup | https://github.com/settings/emails | 4단계: `GitHub e-mail` 입력 |

**② GitHub 계정**

1. https://github.com/signup 에서 이메일 · 비밀번호 · 사용자 이름을 넣고, 이메일로 온 인증 코드를 입력한다. 교육 뒤에도 쓸 이메일로 가입한다.
2. 오른쪽 위 프로필 사진 → **Settings** → **Emails** (https://github.com/settings/emails) 에서 `setup.ps1` 에 넣을 이메일을 확인한다.
   - **Keep my email addresses private** 가 켜져 있으면 그 설명에 나오는 `숫자+아이디@users.noreply.github.com` 주소를 쓴다. 실제 이메일로 커밋하면 GitHub가 올리기(push)를 거부할 수 있다.
3. 2단계 인증을 요구받으면 **Settings** → **Password and authentication** (https://github.com/settings/security) 에서 스마트폰 인증 앱을 등록한다.

- `setup.ps1` 이 함께 묻는 `Git user name` 은 신청할 것이 없다. 커밋에 표시할 이름을 넣는다.

**공공데이터포털 API 활용신청 (1일차 참여자)**

교육 허브 "웹앱 주제"에서 고른 주제의 API를 신청한다. 주제를 못 정했으면 셋 다 신청해도 된다 — 무료다. 승인과 키 반영에 시간이 걸리니 **교육 2~3일 전까지** 끝낸다.

| 주제 카드 | 신청할 데이터 | 신청하는 곳 |
|---|---|---|
| 01 가까운 시험장 찾기 | [한국방송통신전파진흥원_국가기술자격검정 시험장 정보](https://www.data.go.kr/data/15076833/fileData.do) | **오픈 API** 탭 → **활용신청** — 자동승인 |
| 02 자격시험 공지 모아보기 | [한국방송통신전파진흥원_국가기술자격 공지사항](https://www.data.go.kr/data/15125639/openapi.do) | **활용신청** — 자동승인 |
| 03 기금사업 찾기 | [한국방송통신전파진흥원_기금사업정보](https://www.data.go.kr/data/15133304/fileData.do) | **오픈 API** 탭 → **활용신청** — 자동승인 |

1. 로그인한 뒤 위 주소를 열고 **활용신청** 을 누른다. 새 창의 신청서에서 활용목적 **웹 사이트 개발** 을 고르고, 설명은 "교육 실습용 웹앱 개발(비상업)" 정도로 적고, **이용허락범위 동의** 에 체크한 뒤 **활용 신청하기**.
2. 마이페이지에서 승인 상태와 **일반 인증키** 를 본다. 키는 Encoding · Decoding 두 가지다.
3. 브라우저 주소창에 아래 시험 주소를 넣는다. `내_Encoding_키` 자리에 **Encoding** 키를 붙인다.

   | 주제 | 시험 주소 | 성공하면 |
   |---|---|---|
   | 01 | `https://api.odcloud.kr/api/15076833/v1/uddi:94dbb45f-0644-40bf-a5d8-d96cfd26a26b?page=1&perPage=5&serviceKey=내_Encoding_키` | `"currentCount":5` 와 `"data":[` 가 보인다 |
   | 02 | `https://apis.data.go.kr/B552729/kcaApiService_cq1/getCqNotice?serviceKey=내_Encoding_키&pageNo=1&numOfRows=5` | `"resultCode":"00"` 이 보인다 |
   | 03 | `https://api.odcloud.kr/api/15133304/v1/uddi:427e5fb9-3498-4ae9-8841-ab72a7cea63d?page=1&perPage=5&serviceKey=내_Encoding_키` | `"currentCount":5` 와 `"data":[` 가 보인다 |

4. 성공한 화면을 캡처해 사전 준비 회신처(교육 안내 /course)로 보낸다. **주소창의 키 부분은 가리고** 보낸다.

- 키가 등록되지 않았다는 오류가 나면 키 반영 전이다. 1~2시간 뒤 다시 해 본다.
- 키는 메일 · 메신저 · AI 대화창에 붙이지 않는다. 교육 당일 본인이 직접 `.env.local` 에 **Decoding** 키를 넣는다.
- 승인이 끝내 안 나도 교육은 예시 데이터로 배포까지 간다.

## 3. 환경 사전설치 (약 40분)

- **교육에 가져올 노트북** 에서 한다.
- `setup.ps1` 하나가 1 · 2일차에 쓰는 도구를 **모두** 설치한다. 참여하는 날과 상관없이 같은 파일이고, **교육 당일에는 설치하지 않는다** — 로그인 · 점검만 한다.
- 사람은 3-2의 화면에서만 답한다. 작업 공간은 모든 PC에서 **`C:\workspace`** 로 통일한다.
- 걸리는 시간 약 40분은 예상이다(아직 재지 않음). 인터넷 속도에 따라 다르다.

### 3-1. 받기 · 실행

1. 아래 **두 파일**을 받아 **다운로드 폴더에 함께** 둔다. 받는 곳: 메일 첨부, 또는 교육 허브 자료 https://kca-vibe.vercel.app/materials
   - `setup.ps1` — 사전설치 스크립트 (https://kca-vibe.vercel.app/materials/1/setup/download)
   - `AGENTS.global.md` — 에이전트 공통 규칙. 스크립트가 같은 폴더에서 찾아 설치한다 (https://kca-vibe.vercel.app/materials/1/AGENTS.global/download)
2. 시작 메뉴 → `PowerShell` 검색 → **Windows PowerShell** 을 연다 (관리자로 실행 아님).
3. 아래를 복사해 붙여넣고 Enter.

```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\setup.ps1"
```

- 중간에 멈췄으면 같은 명령으로 다시 실행해도 된다 — 끝난 단계는 건너뛴다.
- "그룹 정책" 때문에 실행이 거부되면 전산부서에 요청한다 (6장).

### 3-4. 점검 결과 회신

스크립트 마지막에 **RESULT** 상자가 나온다. 확인한 때 · 항목 수와 함께 `WARN` · `FAIL` 인 줄, 그래픽 장치(`Graphics`) 줄이 나온다. 전체 표는 그 위에 있다.

1. RESULT 상자를 캡처한다.
2. Edge 주소창에 `edge://gpu` 를 넣고, **WebGL** 줄이 `Hardware accelerated` 인지 보이게 캡처한다 — 2일차 3D 실습이 이 PC에서 얼마나 빨리 도는지 보는 것이다. `Software only` 여도 실습은 된다.
3. 두 캡처를 교육 안내(https://kca-vibe.vercel.app/course)에 적힌 회신처로 보낸다. 화면에 이메일 등 개인정보가 보이면 가리고 보낸다.

- `WARN` · `FAIL` 이 있으면 6장에서 해당 줄을 찾아 해 본다. 안 되면 그대로 보내면 강사가 돕는다.
- 자세한 기록은 `C:\workspace\setup-log.txt` 에 남는다.

### 3-5. 스크립트가 처음부터 막힐 때

스크립트가 아예 실행되지 않을 때만 한다. 기본 도구만 직접 설치하고, 나머지는 회신하면 강사가 돕는다. 한 줄씩 붙여넣고 Enter.

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
winget install --id OpenJS.NodeJS.LTS -e --accept-source-agreements --accept-package-agreements
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
mkdir C:\workspace -Force
```

PowerShell을 닫고 **새 창** 에서 아래를 실행한 화면을 캡처해 3-4처럼 회신한다 (새로 설치한 프로그램은 새 창에서만 인식된다). 그다음 `setup.ps1` 을 다시 실행해 본다.

```powershell
(Get-CimInstance Win32_OperatingSystem).Caption; Get-ExecutionPolicy -Scope CurrentUser; node -v; npm -v; codex --version; Test-Path C:\workspace
```

| `Continue anyway? (y/N)` | 관리자 창에서 실행한 것 → Enter로 멈추고 일반 창에서 다시 |
| 스크립트나 설치 파일이 보안 프로그램에 차단된다 | 오류 화면 캡처 → 전산부서 예외 신청(1장 주소) + 회신. 기다리는 동안 3-5로 기본 도구만 직접 설치해 본다 |
| `npm.ps1 파일을 로드할 수 없습니다` · `스크립트를 실행할 수 없으므로` | 실행 정책이 안 바뀌었다 → 스크립트를 다시 실행 (직접 설치는 3-5 첫 줄) |
| `'node'` · `'codex'` · `'ego-browser'` 용어가 인식되지 않습니다 | PowerShell을 닫고 새로 열기 → 그래도 안 되면 로그아웃 후 다시 로그인. ego-browser는 ego lite를 한 번 열어 첫 실행을 마쳤는지 본다 |
| `winget` 이 없다 | Microsoft Store에서 "앱 설치 관리자" 업데이트, 또는 nodejs.org → **LTS** → Windows 설치 프로그램(.msi)을 기본값으로 설치한 뒤 스크립트를 다시 실행 |
| `C:\workspace` 를 만들 수 없다 (액세스 거부) | 기관 PC가 C 드라이브 최상위 폴더 만들기를 막은 경우 → 전산부서에 `C:\workspace` 생성 요청 |
| 관리자 확인 창에서 암호를 묻거나 "예"가 없다 | 관리자 권한 없음 → 전산부서 |
| `SELF_SIGNED_CERT_IN_CHAIN` · `UNABLE_TO_GET_ISSUER_CERT_LOCALLY` | 인터넷망인지 확인 후 회신. 인증서 검사를 끄는 우회 설정은 하지 않는다 |
