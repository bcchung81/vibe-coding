# 보고서 도구 설치 (2일차)

> 2일차 3교시 보고서 실습에 쓰는 **report-harness**(`github.com/bcchung81/report-harness`)를 내 PC에 받고, 내 에이전트에 보고서 명령을 설치합니다. 사람은 Part A만 하고, 나머지는 **내 코드 에이전트** 가 이 파일의 Part B를 읽고 진행합니다.

| 항목 | 내용 |
|---|---|
| 언제 | 2일차 1교시 끝 — 2일차만 참여자는 `00_환경설정.md` Part B를 마친 뒤, 이틀 참여자는 1교시를 시작할 때 |
| 걸리는 시간 | 5~10분 |
| 먼저 할 것 | `setup.ps1` 실행 (오늘 또는 1일차). 스크립트가 저장소를 받고 한 번 설치해 둡니다. 이 문서는 최신으로 맞추고, 빠진 것을 채우고, 동작을 확인합니다 |

## 무엇이 설치되나

| 에이전트 | 설치되는 것 | 보고서 만들 때 |
|---|---|---|
| Claude Code | report-harness 플러그인 — 보고서 명령(`/report-research` · `/report-analyze` · `/report-draft` · `/report-export` · `/report-review` · `/report-doctor` · `/cross-verify`)과 스킬(humanizer 포함) | `이 폴더의 자료로 개조식 보고서 초안 만들어줘` |
| Codex | `kca-report-hwpx` · `humanizer` 스킬 → `~\.agents\skills` | 같은 말 |
| Antigravity | `kca-report-hwpx` · `humanizer` 스킬 → `~\.gemini\config\skills` · `~\.gemini\antigravity-cli\skills` | 같은 말 |

## Part A. 사람이 하는 일

1. 교육 허브 3단계에서 이 파일(`00_보고서도구.md`)을 내려받아 **`C:\workspace`** 에 저장합니다.
2. 내 에이전트를 `C:\workspace` 에서 시작합니다 (`00_환경설정.md` Part A 4번 표).
3. 아래 한 줄을 입력합니다.
   ```
   00_보고서도구.md 파일을 읽고 Part B를 순서대로 진행해줘
   ```
4. 명령 실행 승인 요청은 명령과 이유를 읽고 허용합니다. "재시작해 주세요"가 나오면 `00_환경설정.md` Part A 6번 표대로 합니다.

## Part B. 에이전트 지시문

> **여기부터는 코드 에이전트(Codex · Claude Code · Antigravity)에게 주는 지시입니다.** 공통 규칙은 전역 규칙 파일을 따른다. 명령이 에이전트마다 다르면 지금 쓰는 에이전트의 것만 실행한다.

### R-0. 이 단계의 추가 규칙

1. R-1부터 R-5까지 **순서대로** 진행한다. 단계를 시작할 때 한 줄로 알리고, 확인 명령의 결과로 성공 여부를 보고한다.
2. 작업 공간 밖에 쓰는 곳은 **R-2 표의 전역 스킬 폴더뿐** 이다. 쓰기 전에 명령과 대상 폴더를 보여 주고 승인을 받는다.
3. 이미 최신이면 다시 설치하지 않는다.
4. `LAW_OC` 같은 인증값을 묻지 않고 결과 파일에 적지 않는다. 필요하면 사용자가 `setup.ps1` 을 다시 실행하게 안내한다.
5. 같은 오류로 2번 실패하면 멈추고, 오류 원문 · 원인 추정을 보여 준 뒤 조교를 부르게 한다.

### R-1. 저장소 받기 · 최신으로

저장소 `https://github.com/bcchung81/report-harness` → `C:\workspace\report-harness`

```powershell
git -C C:\workspace\report-harness log -1 --oneline
```

| 결과 | 할 일 |
|---|---|
| 커밋 한 줄이 나온다 | `git -C C:\workspace\report-harness pull --ff-only` 로 최신화 |
| 폴더가 없다 (`cannot change to`) | `git clone --depth 1 https://github.com/bcchung81/report-harness.git C:\workspace\report-harness` |
| `dubious ownership` | 사용자에게 `setup.ps1` 을 다시 실행하게 한다 (스크립트가 `safe.directory` 에 등록한다) |
| pull 실패 (고친 파일이 있다) | `git -C C:\workspace\report-harness status --short` 를 보여 주고 멈춘다. 사용자 판단 없이 되돌리지 않는다 |
| clone 실패 (네트워크) | github.com 접속(보안 프로그램 · 프록시)을 확인하게 하고 조교를 부르게 한다 |

**확인**: `git -C C:\workspace\report-harness log -1 --oneline` → 커밋 한 줄 · `Test-Path C:\workspace\report-harness\dist` → `True`

### R-2. 내 에이전트에 보고서 명령 설치

**Claude Code** — 플러그인

```powershell
claude plugin list
```

| `report-harness` 가 | 실행 |
|---|---|
| 있다 → 갱신 | `claude plugin marketplace update report-harness` → `claude plugin update report-harness@report-harness` |
| 없다 → 설치 | `claude plugin marketplace add C:\workspace\report-harness` → `claude plugin install report-harness@report-harness` |

**Codex · Antigravity** — 스킬 폴더 2개(`kca-report-hwpx` · `humanizer`)

| 에이전트 | `$zip` | `$skills` (전역 스킬 폴더) |
|---|---|---|
| Codex | `kca-report-hwpx-codex.zip` | `$HOME\.agents\skills` |
| Antigravity | `kca-report-hwpx-antigravity.zip` | `$HOME\.gemini\config\skills` 와 `$HOME\.gemini\antigravity-cli\skills` — 폴더마다 한 번씩 |

`$zip` · `$skills` 를 표대로 바꿔 실행한다. 바뀐 것이 없으면 아무것도 하지 않는다 (`setup.ps1` 과 같은 표시 파일 `.source-sha256` 을 쓴다).

```powershell
$h = 'C:\workspace\report-harness'
$zip = 'kca-report-hwpx-codex.zip'
$skills = "$HOME\.agents\skills"
$hash = (Get-FileHash "$h\dist\$zip").Hash
if ((Get-Content "$skills\kca-report-hwpx\.source-sha256" -ErrorAction SilentlyContinue) -ne $hash) {
    Remove-Item "$skills\kca-report-hwpx" -Recurse -Force -ErrorAction SilentlyContinue
    Expand-Archive "$h\dist\$zip" -DestinationPath $skills -Force
    Set-Content "$skills\kca-report-hwpx\.source-sha256" $hash -Encoding ASCII
}
if ((Get-FileHash "$skills\humanizer\SKILL.md" -ErrorAction SilentlyContinue).Hash -ne (Get-FileHash "$h\skills\humanizer\SKILL.md").Hash) {
    Remove-Item "$skills\humanizer" -Recurse -Force -ErrorAction SilentlyContinue
    Copy-Item "$h\skills\humanizer" "$skills\humanizer" -Recurse
}
```

**확인**: Claude Code `claude plugin list` 에 `report-harness` · Codex와 Antigravity `Get-ChildItem $skills -Name` 에 `kca-report-hwpx` · `humanizer`

| korean-law MCP (법령 검색 · 선택) | 위 명령에서 `kordoc` 대신 `korean-law` | 인증값이 들어가므로 직접 등록하지 않는다. `LAW_OC` 가 있으면 사용자가 `setup.ps1` 을 다시 실행하고, 없으면 "korean-law 미등록"으로 기록하고 넘어간다 |

### R-4. 재시작 · 동작 확인

새로 설치한 명령 · 스킬은 **새 세션에서 보인다.** R-1 · R-2에서 바뀐 것이 없으면 1번은 건너뛴다.

1. 사용자에게 재시작(`/exit` → 새 창 → `00_환경설정.md` Part A 4번 표의 **이어서 다시 시작**, Antigravity는 앱을 닫았다 다시 열기)을 안내한다.
2. 사용자가 확인한다.

   | 에이전트 | 확인 |
   |---|---|
   | Claude Code | `/plugin` → report-harness, 이어서 `/report-doctor` |
   | Codex | `/skills` → kca-report-hwpx · humanizer |
   | Antigravity | 에이전트에게 "쓸 수 있는 스킬 이름만 말해줘" |
3. 보고서를 실제로 만들어 보지는 않는다 (3교시에 한다 · 사용량 절약).
