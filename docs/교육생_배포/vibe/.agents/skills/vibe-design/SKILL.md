---

화면을 다듬는다. 기능과 데이터 흐름은 바꾸지 않는다.

1. `PRD.md` 의 "화면" 칸과 `PLAN.md` 를 읽는다. 화면 단계가 하나도 `[x]` 가 아니면 멈추고 `vibe-develop` 스킬부터 하라고 말한다.
2. 사용자가 원하는 느낌을 한 줄로 묻는다 (예: 차분하게 · 글자 크게 · 휴대폰 먼저). 말이 없으면 PRD의 "한 줄 소개"에 맞춘다.
3. `impeccable` 스킬(`setup.ps1` 이 전역에 설치)로 `app/page.tsx` 화면을 다듬는다. `impeccable` 이 없으면 멈추고, `setup.ps1` 결과 표의 impeccable 줄을 확인하라고 안내한다.
4. 지킬 것:
   - 데이터는 서버 라우트 `/api/data` 를 그대로 거친다. "예시 데이터" 표시는 남긴다.
   - 오류 원문은 화면에 내지 않는다.
   - 새 패키지가 필요하면 설치 전에 사용자에게 묻는다.
5. 확인: `npm.cmd run build` 가 통과하는지 보고, 사용자에게 브라우저에서 `PLAN.md` 의 완료 기준을 다시 보라고 알려 준다 (휴대폰 폭으로도).
6. 끝나면 3줄로 보고한다: 바꾼 것 · 확인한 방법 · 다음 (`vibe-develop 스킬로 배포 전 점검해줘`).
