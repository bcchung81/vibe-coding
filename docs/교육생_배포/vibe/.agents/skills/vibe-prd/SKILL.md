주제 카드로 사용자를 인터뷰해 `PRD.md` 를 쓴다. 코드는 고치지 않는다.

1. 주제: `/vibe-prd` 뒤의 번호(예: `02`)로 `topics/` 에서 카드를 찾는다. 번호가 없으면 `topics/` 의 번호 · 제목 목록을 보여 주고 고르게 한다.
2. 카드를 읽고, 만들 앱에 대해 질문을 **5개 이하로 하나씩** 묻는다. 예: 누가 언제 쓰나 · 첫 화면에 꼭 보일 것 · 고르는 조건(지역 · 품목 등) · 보여 주는 방식(카드 · 표) · 빼도 되는 것.
3. 답을 모아 `PRD.md` 를 쓴다.

| 칸 | 내용 |
|---|---|
| 주제 | 카드 번호 · 제목 (예: `02 우산 챙겨?`) |
| 한 줄 소개 | 누가 · 무엇을 · 왜 |
| 화면 | 한 화면에 보일 것, 위에서 아래 순서로 |
| 데이터 | 카드의 API · 쓸 응답 항목 · 고르는 조건 |
| 완료 기준 | 눈으로 확인할 수 있는 문장 3개 (카드의 "완료 기준 예시" 참고) |
| 나중에 | 카드의 "향후 고도화" 중 사용자가 원한 것 — 이번에는 만들지 않는다 |

4. 처음 데이터는 `data/snapshot.json` 이다. 실제 API 연결은 `PLAN.md` 의 마지막 단계에서 한다.
5. 끝나면 `PRD.md` 요약 3줄과 "다음: `/vibe-plan`" 을 말한다.
