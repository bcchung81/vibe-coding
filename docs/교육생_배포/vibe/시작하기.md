# 내 웹앱 시작 폴더 (vibe)

이 폴더 하나가 내 웹앱 저장소다. 규칙(`AGENTS.md`), 명령 3개(`vibe-plan` · `vibe-develop` · `vibe-design`), 주제 카드(`topics\`), Next.js 뼈대가 들어 있다. 위치는 `C:\workspace\vibe` 로 둔다.

## 1. 처음 한 번 (1일차 2교시)

PowerShell에서 이 폴더로 가서 Codex를 연다: `cd C:\workspace\vibe` → `codex`

첫마디:

```
시작하기.md 대로 준비해줘
```

에이전트가 하는 일:

1. 저장소 만들기 — `git init` (이미 저장소면 건너뛴다)
2. 패키지 설치 — `npm.cmd install`
3. 뼈대 확인 — `npm.cmd run build` 가 통과하는지
4. 3줄로 보고하고 내 주제 번호를 묻는다

## 2. 교시별로 부르는 명령

`02` 자리에 내 주제 번호를 넣는다. 번호는 `topics\` 파일 앞 두 자리이고, 교육 웹앱의 "웹앱 주제" 화면 번호와 같다.

| 언제 | 시킬 말 |
|---|---|
| 1교시 — API 설명 읽기: 주제 카드의 API 상세 페이지 → `api-notes.md` | `ego-browser 스킬로 topics 폴더의 02 카드에 있는 API 상세 페이지를 열어서 요청 주소, 요청 변수(필수 여부), 응답 항목을 api-notes.md 표로 저장해줘. 로그인 화면은 열지 마` |
| 2교시 — 기획: 주제 카드로 인터뷰 → `PRD.md` → `PLAN.md` | `vibe-plan 스킬로 주제 02 시작해줘` |
| 3교시 — 한 단계씩 만들기 (단계마다 반복 · AI가 ego-browser로 눌러 보고 보고한다) | `vibe-develop 스킬로 다음 단계 해줘` |
| 3교시 — 실제 API | 아래 3번으로 키를 넣고 `vibe-develop 스킬로 다음 단계 해줘` |
| 막혔을 때 | `vibe-develop 스킬로 이 오류 고쳐줘` 다음 줄에 오류 원문 |
| 3교시 — 화면 다듬기 (impeccable 스킬을 쓴다) | `vibe-design 스킬로 화면 다듬어줘` |
| 4교시 — 배포 전 점검 · 배포 | `vibe-develop 스킬로 배포 전 점검해줘` → 통과하면 `이 폴더를 Vercel 프로덕션으로 배포해줘. 환경변수는 내가 직접 넣을 테니 넣을 이름만 알려줘` |
| 선택 — GitHub | `GitHub에 비공개 저장소를 만들어 올려줘` |

## 3. 키 넣기 (3교시, 본인이 직접)

에이전트에게 키 값을 말하지 않는다. PowerShell에서:

```powershell
Copy-Item .env.example .env.local
notepad .env.local
```

`DATA_GO_KR_KEY=` 뒤에 공공데이터포털 **Decoding** 키를 붙여 넣고 저장한다.

## 4. 명령을 다른 폴더에서도 쓰려면 (전역 설치)

```
이 프로젝트의 vibe 명령을 전역에도 설치해줘
```

에이전트가 `AGENTS.md` 의 "전역 설치" 절차대로 내 PC의 전역 스킬 폴더에 복사한다. 설치가 끝나면 Codex를 다시 연다.
