# 내 웹앱 시작 폴더 (vibe)

이 폴더 하나가 내 웹앱 저장소다. 규칙(`AGENTS.md`), 명령(`/vibe-…`), 주제 카드(`topics\`), Next.js 뼈대가 들어 있다. 위치는 `C:\workspace\vibe` 로 둔다.

## 1. 처음 한 번 (1일차 2교시)

이 폴더에서 에이전트를 연다.

| 에이전트 | 여는 법 |
|---|---|
| Codex | PowerShell에서 `cd C:\workspace\vibe` → `codex` |
| Claude Code | PowerShell에서 `cd C:\workspace\vibe` → `claude` |
| Antigravity | 앱에서 폴더 열기 → `C:\workspace\vibe` |

첫마디:

```
시작하기.md 대로 준비해줘
```

에이전트가 하는 일:

1. 저장소 만들기 — `git init` (이미 저장소면 건너뛴다)
2. 패키지 설치 — `npm.cmd install`
3. 뼈대 확인 — `npm.cmd run build` 가 통과하는지
4. 3줄로 보고하고 내 주제 번호를 묻는다

## 2. 교시별로 부르는 명령

`02` 자리에 내 주제 번호를 넣는다. 번호는 `topics\` 파일 앞 두 자리이고, 교육 웹앱의 "웹앱 주제" 화면 번호와 같다.

| 언제 | Claude Code | Codex · Antigravity |
|---|---|---|
| 2교시 — 주제 카드로 인터뷰 → `PRD.md` | `/vibe-prd 02` | `vibe-prd 스킬로 주제 02 시작해줘` |
| 2교시 — 계획 → `PLAN.md` | `/vibe-plan` | `vibe-plan 스킬로 계획 써줘` |
| 3교시 — 한 단계씩 만들기 (단계마다 반복) | `/vibe-step` | `vibe-step 스킬로 다음 단계 해줘` |
| 3교시 — 실제 API | 아래 3번으로 키를 넣고 `/vibe-step` | `vibe-step 스킬로 다음 단계 해줘` |
| 3교시 — 화면 다듬기 | `impeccable 스킬로 이 화면을 다듬어줘` | 같음 |
| 막혔을 때 | `/vibe-fix` 다음 줄에 오류 원문 | `vibe-fix 스킬로 이 오류 봐줘` 다음 줄에 오류 원문 |
| 4교시 — 배포 전 점검 · 배포 | `/vibe-check` → 통과하면 `Vercel에 프로덕션 배포해줘` | `vibe-check 스킬로 점검해줘` |
| 선택 — GitHub | `GitHub에 비공개 저장소를 만들어 올려줘` | 같음 |

## 3. 키 넣기 (3교시, 본인이 직접)

에이전트에게 키 값을 말하지 않는다. PowerShell에서:

```powershell
Copy-Item .env.example .env.local
notepad .env.local
```

`DATA_GO_KR_KEY=` 뒤에 공공데이터포털 **Decoding** 키를 붙여 넣고 저장한다.

## 4. 명령을 다른 폴더에서도 쓰려면 (전역 설치)

```
이 프로젝트의 vibe 명령을 전역에도 설치해줘
```

에이전트가 `AGENTS.md` 의 "전역 설치" 절차대로 내 PC의 전역 스킬 폴더에 복사한다. 설치가 끝나면 에이전트를 다시 연다.

## 5. 폴더 구조

| 위치 | 내용 |
|---|---|
| `AGENTS.md` · `CLAUDE.md` | 이 프로젝트 규칙. 공통 규칙은 `setup.ps1` 이 전역에 이미 설치했다 |
| `.agents\skills\` · `.claude\skills\` | vibe 명령 5개 — 내용은 같고, 에이전트마다 읽는 폴더만 다르다 |

| `app\page.tsx` | 화면 |
| `app\api\data\route.ts` | 서버 라우트 — 처음엔 스냅샷, 키를 넣으면 실제 API |
| `vercel.json` | 배포 지역 서울(`icn1`) |
