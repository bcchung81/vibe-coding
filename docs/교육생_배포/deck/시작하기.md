# 3D 발표 덱 시작 폴더 (deck)

이 폴더 하나가 내 발표 덱이다. 규칙(`AGENTS.md`), 명령 3개(`deck-plan` · `deck-build` · `deck-export`), 6장짜리 예시 덱, 3D 장면 3개(지구본 · 막대 · 파동)가 들어 있다. 위치는 `C:\workspace\deck` 로 둔다. 보고서는 옆 폴더 `C:\workspace\report` 에 있다.

## 1. 처음 한 번 (2일차 3교시)

교육 허브에서 받은 한 줄로 이 폴더를 만든 뒤, PowerShell에서 Codex를 연다: `cd C:\workspace\deck` → `codex`

첫마디:

```
시작하기.md 대로 준비해줘
```

에이전트가 하는 일:

1. 패키지 설치 — `npm.cmd install`
2. 덱 확인 — `npm.cmd run build` 가 통과하는지
3. 3줄로 보고하고, 새 창에서 `npm.cmd run dev` 를 켜라고 안내한다

**새 PowerShell 창**에서 덱을 켠다 — 이 창은 끄지 않는다.

```powershell
cd C:\workspace\deck; npm.cmd run dev
```

창에 나온 주소(http://localhost:5173)를 브라우저로 연다. 지구본이 도는 표지가 보이면 된다.

## 2. 덱 다루기

| 키 · 주소 | 하는 일 |
|---|---|
| → · Space · 클릭 / ← | 다음 장 / 앞 장 |
| 주소 끝 `#3` | 3장으로 바로 |
| P | 조절 패널 숨기기 · 열기 — 색 · 속도 · 빛 번짐 · 가벼운 모드 |
| F | 전체 화면 |

- 조절 패널에서 맞춘 값은 새로고침하면 사라진다. 패널의 **값 복사** 를 눌러 Codex에 붙여 넣으면 `src/params.js` 에 고정된다 — 영상도 이 값으로 찍는다.
- 그래픽 가속이 없는 PC는 **가벼운 모드** 가 저절로 켜진다(왼쪽 아래 표시). 빛 번짐을 끄고 점을 줄인다.

## 3. 교시별로 부르는 명령

| 언제 | 시킬 말 |
|---|---|
| 3교시 — 맛보기 | `deck-build 스킬로 표지 3D 장면 색을 기관 색으로 바꿔줘` |
| 4교시 — 줄거리 | `deck-plan 스킬로 ..\report 폴더의 보고서를 6장 발표 줄거리로 만들어줘` → `deck-plan.md` 를 열어 순서를 직접 고친다 |
| 4교시 — 장 만들기 | `deck-build 스킬로 deck-plan.md 1장부터 차례로 만들어줘` |
| 4교시 — 3D | `deck-build 스킬로 3장 막대를 보고서 표 숫자로 바꿔줘` |
| 4교시 — 점검 | `ego-browser 스킬로 localhost:5173 덱의 모든 장을 넘겨 보고 글자가 넘치거나 겹치는 장을 알려줘` |
| 5교시 — 영상 | `deck-export 스킬로 표지 · 3장 · 마지막 장을 이어 30초 영상으로 만들어줘` |
| 5교시 — 다시 | `장마다 8초로 다시 만들어줘` · `메신저용 GIF로도 만들어줘` |

## 4. 막히면

| 증상 | 할 일 |
|---|---|
| 화면이 끊긴다 | 조절 패널에서 **가벼운 모드** 를 켠다 |
| 3D가 안 보이고 글만 보인다 | Edge 주소창 `edge://gpu` 의 WebGL 줄을 캡처해 빨강 컵 |
| AI가 새 패키지를 설치하려 한다 | 거절한다 — 이 폴더 규칙이다 |
| 영상 만들기가 FFmpeg를 못 찾는다 | 새 창에서 `ffmpeg -version` → 안 나오면 조교 |
