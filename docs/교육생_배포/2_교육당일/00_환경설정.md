> 1일차 · 2일차 모두 1교시에 이 파일로 시작합니다. 날마다 내용이 같습니다.
> 설치는 교육 전에 **`setup.ps1`** 로 끝냈습니다 (`00_사전안내.md` 3장). 오늘은 받은 계정으로 로그인하고, **Codex** 가 이 파일의 Part B를 읽고 설치 결과를 점검합니다. 당일에 새로 설치하지 않습니다.

## Part A. 사람이 하는 일 (1교시)

1. **받은 계정으로 로그인합니다.** 교육 당일 받은 Codex(ChatGPT) 계정을 씁니다 (받는 방법은 강사가 안내). **Orca** 를 열고 새 터미널(PowerShell)에서 입력하고, 브라우저가 열리면 받은 계정으로 로그인합니다.
   ```powershell
   codex login
   codex login status
   ```
   `Logged in using ChatGPT` 이면 됩니다. API 키로 로그인되어 있으면 부록의 로그인 줄대로 **받은 계정** 으로 다시 로그인합니다.
2. 이 파일(`C:\workspace\00_환경설정.md`)은 `setup.ps1` 이 교육 허브에서 미리 받아 두었습니다. 없거나 강사가 새 판을 알리면 교육 허브 자료에서 받아 **`C:\workspace`** 에 저장합니다.
3. Codex를 실행합니다.

   | 시작 | 이어서 다시 시작 |
   |---|---|
   | `cd C:\workspace` → `codex --yolo` | `cd C:\workspace` → `codex resume --last --yolo` |

   Codex를 처음 열면 아래를 묻습니다.

   | 처음 열 때 묻는 것 | 이렇게 |
   |---|---|
   | 이 폴더를 신뢰할지 | Yes |
   | 첫 화면 설정(테마 등) | 기본값 그대로 Enter |
   | Windows 샌드박스 설정 | 권장(기본) 선택 → 관리자 확인 창에서 "예" |

4. 아래 한 줄을 입력합니다.
   ```
   00_환경설정.md 파일을 읽고 Part B를 순서대로 진행해줘
   ```
5. 이후에는 에이전트가 안내하는 것만 하면 됩니다.

   | 이런 게 나오면 | 이렇게 |
   |---|---|
   | 명령 실행 승인 요청 | 명령과 이유를 읽어 보고 허용 |
   | "별도 창에서 실행해 주세요" | Orca 새 터미널을 열어 안내받은 명령을 직접 입력 (로그인용) |
   | 브라우저 로그인 · 가입 | 직접 처리 후 에이전트 창에 "완료" 입력 |
   | "재시작해 주세요" | `/exit` → 창 모두 닫기 → 새 창 → 3번 표의 **이어서 다시 시작** |

## Part B. 에이전트 지시문

> **여기부터는 Codex에게 주는 지시입니다.** 공통 규칙은 전역 규칙 파일을 따른다. 설치는 사용자가 교육 전에 `setup.ps1` 로 끝냈다. 결과를 확인하고, 실패한 항목만 고치고, 계정 로그인을 안내한다.

### B-0. 이 단계의 추가 규칙

1. B-1부터 B-6까지 **순서대로** 진행한다. 단계를 시작할 때 한 줄로 알리고, 확인 명령의 결과로 성공 여부를 보고한다.
2. **`setup.ps1` 이 끝낸 항목은 다시 설치하지 않는다.** `WARN` · `FAIL` 항목만 사용자 승인을 받아 조치한다.
3. **PATH · 실행 정책은 직접 바꾸지 않는다.** 사용자에게 `setup.ps1` 을 다시 실행하게 안내한다.
4. 사람만 할 수 있는 일(계정 가입, 브라우저 로그인, 관리자 승인, ego lite 첫 실행)은 안내한 뒤 "완료"를 기다린다. 대화형 로그인 명령은 사용자가 **Orca 새 터미널** 에서 입력하게 한다.
5. 키 · 토큰 · 인증값을 요구하지 않고, 결과 파일에 적지 않는다.

### B-1. 설치 결과 확인

1. 로그에서 결과 줄만 읽어 표로 요약한다.
   ```powershell
   Select-String -Path setup-log.txt -Pattern ' \| (OK|SKIP|WARN|FAIL) \| '
   ```
   파일이 없으면 교육 전 설치를 하지 않은 PC다. 사용자에게 조교를 부르게 하고, 다운로드 폴더의 `setup.ps1` 을 일반 PowerShell 창에서 실행하게 안내한다(약 50분 — `00_사전안내.md` 3-1). 끝나면 B-1부터 다시 한다.
2. 모두 `OK` · `SKIP` 이면 B-3으로 간다. `WARN` · `FAIL` 이 있으면 그 항목만 지금 상태를 확인한다 (아래에서 해당 줄만 실행).
   ```powershell
   git --version; python --version; gh --version; vercel.cmd --version; ffmpeg -version
   codex mcp list
   Get-ChildItem $HOME\.agents\skills -Name -ErrorAction SilentlyContinue
   Test-Path $HOME\.codex\AGENTS.md
   Select-String default_subagent_ $HOME\.codex\config.toml
   foreach ($r in 'slop-rewrite','cokacmotion','vibe-coding-start') { git -C C:\workspace\$r log -1 --oneline }
   Test-Path C:\workspace\vibe\AGENTS.md, C:\workspace\deck\AGENTS.md
   ```

### B-3. ego lite — 에이전트 브라우저

ego lite는 사용자가 교육 전에 직접 설치한다(`00_사전안내.md` 3-3).

1. 확인한다.
   ```powershell
   Get-Command ego-browser
   ego-browser nodejs -e "console.log('ego-browser ready')"
   ```
2. `ego-browser ready` 가 나오면 B-4로 간다.
3. 명령이 없으면: ego lite를 설치했는지, 한 번 열어 첫 실행을 마쳤는지 사용자에게 묻는다. 설치하지 않았으면 https://lite.ego.app 에서 설치하게 하고(SmartScreen은 "추가 정보 → 실행"), **"Chrome 데이터 가져오기"는 아니오**로 답하게 한다. 끝나면 재시작 체크포인트를 따른다.
4. 오늘 Codex는 `--yolo`(승인 · 샌드박스 없음)로 돈다. 연결이 막히면 보안 프로그램 · 프록시 문제다 — 오류 원문을 보여 주고 조교를 부르게 한다.

### B-4. 다른 로그인 — 오늘은 하지 않는다

1. **GitHub** — 1 · 2일차 실습에서 쓰지 않으므로 로그인하지 않는다(커밋은 내 PC 안에서만 한다).
2. **Vercel** — 여기서는 하지 않는다. 1일차 배포 직전에 vercel.com 가입 · 토큰 발급 · `.env.local` 의 `VERCEL_TOKEN` 을 사람이 하고, `vibe-develop` 스킬이 안내한다.

- 도구별 버전: Codex · Git · Node.js · Python · GitHub CLI · Vercel CLI · FFmpeg
- 로그인 상태: Codex(ChatGPT 계정 / API 키)
- MCP 등록 상태 · 스킬(impeccable · think · slop-rewrite · aimotion · ego-browser) · 에이전트 규칙(전역 규칙 파일 · 하위 에이전트 상한)
- `setup.ps1` 에서 실패했다가 B-2에서 고친 항목, 끝내 실패 · 건너뛴 항목과 그 이유

**토큰 · 비밀번호 · 인증값 · 이메일 주소는 적지 않는다.**

### B-6. 재시작 · 동작 확인

MCP · 스킬 · 전역 규칙은 **새 세션에서 불러와진다.**

1. 사용자에게 재시작(`/exit` → 새 창 → Part A 3번 표의 **이어서 다시 시작**)을 안내한다.
2. 사용자가 직접 확인한다.

   | 확인할 것 | Codex에 입력 |
   |---|---|
   | MCP (sequential-thinking · kordoc) | `/mcp` |
   | 스킬 (impeccable · think · slop-rewrite · aimotion · ego-browser) | `/skills` |
3. 에이전트가 직접 시험한다 (토큰 절약 — 짧게).
   - **전역 규칙**: 지금 적용 중인 공통 규칙의 장 제목을 한 줄로 말한다. 말하지 못하면 전역 규칙 파일(`~\.codex\AGENTS.md`)이 읽히지 않은 것이다.
   - **ego-browser**: 교육 허브 https://kca-vibe.vercel.app/course 를 열어 페이지 제목 한 줄만 말한다. 로그인이 필요한 곳은 열지 않는다.
4. `환경점검결과.md` 에 동작 확인 결과를 덧붙이고, 마지막에 이렇게 알린다: **"점검이 끝났습니다. 이 파일을 강사에게 제출해 주세요."**

## 부록. 문제 해결

| 증상 | 조치 |
|---|---|
| `setup-log.txt` 가 없다 | 교육 전 설치를 하지 않은 PC → 조교. 다운로드 폴더의 `setup.ps1` 을 일반 PowerShell 창에서 실행(`00_사전안내.md` 3-1) |
| `setup.ps1` 이 실행되지 않는다 · 보안 경고 | "디지털 서명되지 않았습니다"면 `Unblock-File "$env:USERPROFILE\Downloads\setup.ps1"` 후 다시. "그룹 정책" 메시지면 전산부서 |
| `PowerShell runs in ConstrainedLanguage mode` | 기관 보안 정책(AppLocker · WDAC)이 스크립트를 제한한 PC다. 우회하지 말고 전산부서 |
| `Continue anyway? (y/N)` | 관리자 권한 창에서 실행한 것. Enter로 멈추고 일반 PowerShell 창에서 다시 실행 |
| 설치했는데 `명령을 찾을 수 없습니다` | PowerShell · 터미널 창을 모두 닫고 새 창. 그래도 안 되면 `setup.ps1` 다시 실행(PATH 보정) → 그래도 안 되면 로그아웃 후 다시 로그인 |
| `npm.ps1 파일을 로드할 수 없습니다` | 실행 정책 미설정 → `setup.ps1` 다시 실행 |
| Codex가 로그인 안 됨 · API 키로 로그인됨 | 별도 창에서 `codex logout` → `codex login` → **교육에서 받은 ChatGPT 계정** 으로 로그인. 확인: `codex login status` → `Logged in using ChatGPT` |
| 사용량 한도에 걸렸다 | Codex에서 `/status` 로 남은 한도와 풀리는 시각 확인. **API 키 · 추가 결제(크레딧)로 넘기지 않는다.** 강사에게 알린다 |
| Windows 샌드박스 설정이 실패한다 (Codex) | 관리자 승인 창을 거절했거나 기관 정책으로 막힌 경우. 조교를 부른다 |
| 명령마다 승인 요청이 뜬다 | 정상이다. 명령을 읽고 허용 |
| `ego-browser` 를 찾을 수 없다 | ego lite를 한 번 열어 첫 실행을 마쳤는지 → 새 창. 설치하지 않았으면 `00_사전안내.md` 3-3 |
| `python` 이 Microsoft Store를 연다 | PowerShell 창을 모두 닫고 새 창에서 다시 확인. 그래도 안 되면 `setup.ps1` 다시 실행 |
| `SELF_SIGNED_CERT_IN_CHAIN` · `UNABLE_TO_GET_ISSUER_CERT` | 인터넷망 PC인지 확인. **`strict-ssl false` 로 우회하지 않는다** |
| `/mcp` 에서 MCP가 실패로 보인다 | `node -v` 가 v22 이상인지, `codex mcp get <이름>` 의 명령이 `cmd` · 인자가 `/c npx ...` 인지 확인. 첫 실행은 패키지를 내려받느라 늦을 수 있으니 재시작 후 한 번 더 |
| 교육이 끝났다 | 공용 PC면 반드시 `codex logout` 으로 로그아웃 · ego lite도 로그아웃 |
