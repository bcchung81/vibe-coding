# 이거 몇 칼로리?

> 먹거리 · 식약처 식품영양성분DB · 난이도 하

| 항목 | 내용 |
|---|---|
| 만드는 것 | 음식 이름을 검색하면 열량 · 탄수화물 · 단백질 · 지방 · 당류 · 나트륨을 카드로 보여 주는 한 화면 |
| API | [식품의약품안전처_식품영양성분DB정보](https://www.data.go.kr/data/15127578/openapi.do) |
| 승인 · 한도 | 개발계정 자동승인 · 하루 10,000회 |
| 응답 형식 | JSON (`type=json`, 빼면 XML) |
| 강사가 미리 주는 것 | 쓸 항목 이름표(아래 "응답에서 쓸 항목"), `snapshot.json` |

이 파일이 **주제 카드**다. 시작 폴더(`vibe.zip`)의 `topics\` 에도 들어 있다. 1일차 2교시 첫 명령은 `/vibe-prd 04` — 에이전트가 이 카드를 읽고 인터뷰를 시작한다.

## 교육 시간 안에 만드는 것

| 언제 | 할 일 |
|---|---|
| 1일차 3교시 (화면 30분) | 검색창 → `snapshot.json` 에서 이름이 맞는 음식을 영양 카드로 보여 주기 |
| 1일차 3교시 (실제 API 20분) | `/api/data` 라우트가 스냅샷 대신 실제 API를 검색어로 부르게 바꾸기 |

완료 기준 예시

- "김치찌개"를 검색하면 카드에 열량(kcal)과 영양소 5가지가 단위와 함께 보인다
- 결과가 없으면 "찾는 음식이 없습니다. 다른 이름으로 검색해 보세요"가 보인다
- 카드마다 기준량(예: 100g)이 함께 보인다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://apis.data.go.kr/1471000/FoodNtrCpntDbInfo03/getFoodNtrCpntDbInq03
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | |
| `FOOD_NM_KR` | | `김치찌개` | 식품명 (검색어) |
| `type` | | `json` | |
| `numOfRows` | | `20` | |
| `pageNo` | | `1` | |
| `FOOD_CAT1_NM` | | | 식품대분류명으로 좁히기 |

시험 URL (브라우저, Encoding 키)

```
https://apis.data.go.kr/1471000/FoodNtrCpntDbInfo03/getFoodNtrCpntDbInq03?serviceKey=내_Encoding_키&FOOD_NM_KR=김치찌개&type=json&numOfRows=20&pageNo=1
```

## 응답에서 쓸 항목

항목 이름이 번호뿐이라 이 표대로 이름을 붙이게 시킨다.

| 항목 | 뜻 | 단위 |
|---|---|---|
| `FOOD_NM_KR` | 식품명 | |
| `SERVING_SIZE` | 영양성분 함량 기준량 | 예: 100g |
| `AMT_NUM1` | 에너지 | kcal |
| `AMT_NUM6` | 탄수화물 | g |
| `AMT_NUM3` | 단백질 | g |
| `AMT_NUM4` | 지방 | g |
| `AMT_NUM7` | 당류 | g |
| `AMT_NUM13` | 나트륨 | mg |
| `DB_CLASS_NM` | 품목대표 / 상용제품 | 구분 |

## 막히는 곳

- 같은 이름이 여러 줄 온다 (대표값 · 가공식품 · 음식점 메뉴). 첫 화면은 `DB_CLASS_NM` 으로 구분해 보여 주거나 하나만 고르게 한다 — PRD에서 정한다.
- 기준량이 "100g"처럼 글자로 온다. 1인분으로 바꾸지 않고 기준량을 그대로 보여 준다.
- 값이 비어 있는 영양소가 있을 수 있다. "정보 없음"으로 보이게 한다.
- 검색어가 일부만 맞아도 나오는지(부분 일치)는 리허설에서 확인한다.
