# 군립공원 기지국 찾기

> 무선국 · 한국방송통신전파진흥원 산악지역 기지국현황(군립공원) · 난이도 하

| 항목 | 내용 |
|---|---|
| 만드는 것 | 군립공원 27곳의 이동통신 기지국 수를 보여 주고, 공원을 누르면 4G · 5G · 3G로 나눈 개수와 주소 목록이 펼쳐지는 한 화면 |
| API | [한국방송통신전파진흥원_산악지역 기지국현황(군립공원)](https://www.data.go.kr/data/15133040/fileData.do) — 파일데이터(CSV)를 포털이 바꿔 주는 **자동변환 오픈API** |
| 승인 · 한도 | 자동승인 — 신청 직후 바로 불렸다(2026-11-08). 하루 한도는 페이지에 없다 |
| 응답 형식 | JSON (기본) · 전체 889행 · 1회성 데이터 (이 카드는 2024-08-01 판) |
| 미리 받은 데이터 | 시작 폴더 `data\08.json` — 889행 전체. `vibe-plan` 이 `data\snapshot.json` 으로 복사한다 |

이 파일이 **주제 카드**다. 시작 폴더(`C:\workspace\vibe`)의 `topics\` 에도 들어 있다. 1일차에는 `ego-browser` 로 위 API 페이지의 오픈API 명세를 읽어 `api-notes.md` 를 만들고(조사), `vibe-plan 스킬로 주제 08 API 시험해줘` 로 5건만 불러 본 뒤(API 시험), 그 데이터로 `vibe-plan 스킬로 화면 구성 기획해줘` 를 한다.

## 교육 시간 안에 만드는 것

| 단계 | 할 일 |
|---|---|
| API 시험 | 5건만 불러 본다 — 경도 · 위도가 글자인 것, 같은 주소가 여러 번 나오는 것, 주소의 시 · 도 이름 모양 |
| 데이터 연결 | `/api/data` 라우트가 자동변환 API를 한 번 불러 889행 전체를 돌려주게 하기 (`perPage=900`) |
| 화면 구성 → 디자인 입히기 | 공원을 카드로 — 공원 이름 · 기지국 수, 많은 순, 맨 위에 "군립공원 27곳 · 기지국 889곳" → 실제 데이터 위에 디자인 |
| 기능 하나씩 | 공원 카드 누르면 펼치기 → 4G · 5G · 3G 거르기 |

완료 기준 예시

- 첫 화면에 공원 27곳이 기지국 수와 함께 많은 순으로 보이고, 위에 "군립공원 27곳 · 기지국 889곳"이 보인다
- 명지산 카드를 누르면 "4G 26 · 5G 4 · 3G 10"처럼 용도별 개수와 기지국 주소 목록이 펼쳐진다
- 5G를 고르면 5G 기지국만 세어 공원별 개수와 위 합계("기지국 148곳")가 바뀐다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 키 오류가 난다 |

- 파일 내려받기와 달리 자동변환 API는 활용신청을 해야 키로 부를 수 있다. 교육 전에 아래 시험 URL로 목록이 오는지 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://api.odcloud.kr/api/15133040/v1/uddi:10052cb8-9806-495f-83be-e429b8847f2d
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | 공공데이터포털 인증키. 없으면 401 |
| `page` | | `1` | 페이지 번호 (기본 1) |
| `perPage` | | `900` | 한 번에 받을 행 수 (기본 **10**) — 889행을 한 번에 받으려면 900 |
| `returnType` | | `JSON` | 기본 JSON. `XML` 이면 XML |

시험 URL (브라우저, Encoding 키)

```
https://api.odcloud.kr/api/15133040/v1/uddi:10052cb8-9806-495f-83be-e429b8847f2d?page=1&perPage=5&serviceKey=내_Encoding_키
```

## 응답에서 쓸 항목

목록은 `data` 에 있다. `totalCount` 는 전체 행 수. 한 행이 기지국 하나다.

| 항목 | 뜻 | 화면 |
|---|---|---|
| `공원명` | 군립공원 이름 27곳 (가장 많은 곳 `불영계곡` 127행) | 카드 제목 · 묶는 기준 |
| `용도` | `4G`(525행) · `3G`(216행) · `5G`(148행) | 용도별 개수 · 거르기 |
| `주소` | 기지국 주소 (예: `경기 가평군 북면 도대리 산266`) | 펼침 목록 |
| `경도` · `위도` | 좌표 — 글자 (예: `"127.457551"`) | 쓰지 않는다 (고도화 지도용) |

## 막히는 곳

- 항목 이름이 한글이다. 코드에서는 `item["공원명"]` 처럼 대괄호로 읽게 한다.
- `perPage` 를 빼면 10행만 온다. "기지국이 10곳뿐"이면 이것부터 본다.
- 기지국 번호 같은 고유 칸이 없다. 같은 주소가 좌표만 다르게 여러 번 나온다 — 한 행을 기지국 하나로 세고, 목록의 key는 배열 위치를 붙인다.
- 공원 목록은 미리 정하지 말고 데이터에서 뽑는다 (27곳).
- 주소의 시 · 도 이름이 섞여 있다 — `경상남도` · `경남`, `전라북도` · `전북` · `전북특별자치도`, `강원도` · `강원` · `강원특별자치도` 처럼 첫 낱말이 16가지다. 시 · 도로 거르기를 넣으면 짧은 이름으로 맞춘다.
- 통신사(SKT · KT · LG U+) 칸이 없다. 통신사는 오픈API "산악지역 이동통신 찾기"에 있다 — 전파누리(spectrummap.kr)에서 키를 따로 받는다.
- 2024-08-01 기준 1회성 데이터다. "지금 터지는 곳" 같은 표시는 넣지 않는다.
