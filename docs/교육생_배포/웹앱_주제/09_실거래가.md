# 우리 동네 실거래가

> 주거 · 국토교통부 아파트 매매 실거래가 · 난이도 중

| 항목 | 내용 |
|---|---|
| 만드는 것 | 구를 고르면 지난달 아파트 매매 거래를 단지 · 면적 · 금액 표로 보여 주는 한 화면 |
| API | [국토교통부_아파트 매매 실거래가 자료](https://www.data.go.kr/data/15126469/openapi.do) |
| 승인 · 한도 | 개발계정 자동승인 · 하루 10,000회 |
| 응답 형식 | **XML만** — 서버 라우트에서 JSON으로 바꾼다 |
| 강사가 미리 주는 것 | 구 이름 ↔ 지역코드(`LAWD_CD` 5자리) 표, JSON으로 바꿔 둔 `snapshot.json` |

이 파일이 **주제 카드**다. 시작 폴더(`vibe.zip`)의 `topics\` 에도 들어 있다. 1일차 2교시 첫 명령은 `/vibe-prd 09` — 에이전트가 이 카드를 읽고 인터뷰를 시작한다.

## 교육 시간 안에 만드는 것

| 언제 | 할 일 |
|---|---|
| 1일차 3교시 (화면 30분) | 구 고르기 → `snapshot.json` 의 거래를 표로 보여 주고 금액순 · 날짜순 정렬 |
| 1일차 3교시 (실제 API 20분) | `/api/data` 라우트가 실제 API(XML)를 불러 JSON으로 바꿔 돌려주게 하기 |

완료 기준 예시

- 구를 고르면 단지명 · 동 · 전용면적 · 층 · 금액 · 계약일 표가 보인다
- 금액이 "8억 2,500만 원"처럼 읽기 쉽게 보이고, 금액순 정렬이 숫자 크기대로 된다
- 해제된 거래는 빼거나 "해제" 표시가 붙는다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | |
| `LAWD_CD` | ● | `11110` | 지역코드 — 법정동코드 앞 5자리 (예시는 서울 종로구) |
| `DEAL_YMD` | ● | `202609` | 계약 연월 (YYYYMM) |

시험 URL (브라우저, Encoding 키)

```
https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade?serviceKey=내_Encoding_키&LAWD_CD=11110&DEAL_YMD=202609
```

## 응답에서 쓸 항목

| 항목 | 뜻 | 화면 |
|---|---|---|
| `aptNm` | 단지명 | 표 첫 칸 |
| `umdNm` | 법정동 | 표 |
| `excluUseAr` | 전용면적 (㎡) | 표 |
| `floor` | 층 | 표 |
| `dealAmount` | 거래금액 (만 원) | "8억 2,500만 원" |
| `dealYear` · `dealMonth` · `dealDay` | 계약일 | "9.14" |
| `buildYear` | 건축년도 | 작은 글씨 |
| `cdealType` | 해제 여부 | 해제면 빼거나 표시 |

## 막히는 곳

- 응답이 XML뿐이다. 서버 라우트에서 XML을 JSON으로 바꾸게 시킨다.
- 금액이 `"82,500"` 처럼 쉼표 섞인 글자로 올 수 있다. 숫자로 바꾼 뒤 정렬하게 한다.
- 거래 신고 기한(계약 후 30일) 때문에 이번 달은 거래가 적다. 기본값은 **지난달**로 하고, 달 계산은 한국 시간 기준으로 한다.
- 명세 표에는 `pageNo` · `numOfRows` 가 없다. 거래가 많은 구에서 몇 건까지 오는지 리허설에서 확인한다.
