# 숨쉬기 괜찮아?

> 대기질 · 한국환경공단 에어코리아 · 난이도 하

| 항목 | 내용 |
|---|---|
| 만드는 것 | 시도를 고르면 측정소별 미세먼지 · 초미세먼지 등급을 색 카드로 보여 주는 한 화면 |
| API | [한국환경공단_에어코리아_대기오염정보](https://www.data.go.kr/data/15073861/openapi.do) |
| 승인 · 한도 | 개발계정 자동승인 · **하루 500회** (10종 중 가장 적다) |
| 응답 형식 | JSON (`returnType=json`, 빼면 XML) |
| 강사가 미리 주는 것 | 시도 이름 목록, `snapshot.json` |

이 파일이 **주제 카드**다. 시작 폴더(`vibe.zip`)의 `topics\` 에도 들어 있다. 1일차 2교시 첫 명령은 `/vibe-prd 03` — 에이전트가 이 카드를 읽고 인터뷰를 시작한다.

## 교육 시간 안에 만드는 것

| 언제 | 할 일 |
|---|---|
| 1일차 3교시 (화면 30분) | 시도 고르기 → `snapshot.json` 의 측정소를 등급 색 카드로 보여 주기 |
| 1일차 3교시 (실제 API 20분) | `/api/data` 라우트가 스냅샷 대신 실제 API를 부르게 바꾸고 10분 캐시 |

완료 기준 예시

- 시도를 고르면 측정소 카드에 미세먼지 · 초미세먼지 값과 등급(좋음 · 보통 · 나쁨 · 매우나쁨)이 보인다
- 측정값이 없는 측정소는 "측정 안 됨"으로 보인다
- 새로고침을 여러 번 해도 10분 안에는 API를 다시 부르지 않는다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소 (시도별 실시간 측정정보 조회)

```
https://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getCtprvnRltmMesureDnsty
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | |
| `sidoName` | ● | `서울` | 시도 이름 (한글) |
| `returnType` | | `json` | |
| `numOfRows` | | `100` | 측정소가 수십 곳이라 넉넉히 |
| `pageNo` | | `1` | |
| `ver` | | `1.0` | 오퍼레이션 버전 |

시험 URL (브라우저, Encoding 키)

```
https://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getCtprvnRltmMesureDnsty?serviceKey=내_Encoding_키&sidoName=서울&returnType=json&numOfRows=100&pageNo=1&ver=1.0
```

## 응답에서 쓸 항목

| 항목 | 뜻 | 화면 |
|---|---|---|
| `stationName` | 측정소명 | 카드 제목 |
| `dataTime` | 측정일시 | "11:00 기준" |
| `pm10Value` · `pm25Value` | 미세먼지 · 초미세먼지 농도 | 숫자 |
| `pm10Grade` · `pm25Grade` | 24시간 등급 | 1 좋음 · 2 보통 · 3 나쁨 · 4 매우나쁨 → 색 |
| `khaiGrade` | 통합대기환경지수 등급 | 카드 배경 |
| `pm10Flag` · `pm25Flag` | 장비점검 · 통신장애 같은 상태 | 값이 있으면 "측정 안 됨" |

## 막히는 곳

- 하루 500회라 새로고침마다 부르면 금방 닿는다. 서버 라우트에 10분 캐시를 두게 시킨다.
- 점검 중인 측정소는 값이 `-` 이거나 등급이 비어 온다. 숫자로 바꾸기 전에 확인하게 한다.
- 값이 숫자가 아니라 글자(`"68"`)로 온다.
- `sidoName` 은 한글이라 주소에 넣을 때 인코딩이 필요하다. 코드에서는 `URLSearchParams` 로 조립하게 시킨다.

## 향후 고도화 (교육 시간 밖 — 기록만)

- 내 위치 가까운 측정소 — 측정소정보(별도 API) + 위치 권한
- 내일 예보 — "대기질 예보통보 조회" 기능
- 시간대별 그래프 — 측정소별 실시간 측정정보를 여러 시간 받기
- 나쁨일 때 알림
