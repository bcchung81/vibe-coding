# 가까운 시험장 찾기

> 자격 · 한국방송통신전파진흥원 국가기술자격검정 시험장 · 난이도 하

| 항목 | 내용 |
|---|---|
| 만드는 것 | 시 · 도를 고르거나 이름을 넣으면 국가기술자격검정 시험장을 주소 · 시험장 수 · 가용인원 카드로 보여 주는 한 화면 |
| API | [한국방송통신전파진흥원_국가기술자격검정 시험장 정보](https://www.data.go.kr/data/15076833/fileData.do) — 파일데이터(CSV)를 포털이 바꿔 주는 **자동변환 오픈API** |
| 승인 · 한도 | 자동승인 — 신청 직후 바로 불렸다(2026-11-07). 하루 한도는 페이지에 없다 |
| 응답 형식 | JSON (기본) · 전체 218행 · 해마다 갱신 (이 카드는 2026-08-18 판) |
| 미리 받은 데이터 | 시작 폴더 `data\01.json` — 218행 전체. `vibe-plan` 이 `data\snapshot.json` 으로 복사한다 |

이 파일이 **주제 카드**다. 시작 폴더(`C:\workspace\vibe`)의 `topics\` 에도 들어 있다. 1일차에는 `ego-browser` 로 위 API 페이지의 오픈API 명세를 읽어 `api-notes.md` 를 만들고(조사), `vibe-plan 스킬로 주제 01 API 시험해줘` 로 5건만 불러 본 뒤(API 시험), 그 데이터로 `vibe-plan 스킬로 화면 구성 기획해줘` 를 한다.

## 교육 시간 안에 만드는 것

| 단계 | 할 일 |
|---|---|
| API 시험 | 5건만 불러 본다 — 숫자 칸이 숫자로 오는지, 주소의 시 · 도 이름 모양, 0인 칸 |
| 데이터 연결 | `/api/data` 라우트가 자동변환 API를 한 번 불러 218행 전체를 돌려주게 하기 (`perPage=300`) |
| 화면 구성 → 디자인 입히기 | 시험장을 카드로 — 이름 · 주소 · 시험장 수, 맨 위에 "전체 N곳" → 실제 데이터 위에 디자인 |
| 기능 하나씩 | 시 · 도 고르기 → 이름 · 주소 검색 |

완료 기준 예시

- 첫 화면에 시험장 카드가 이름 · 주소와 함께 보이고, 위에 "전체 N곳"이 보인다
- 시 · 도에서 하나를 고르면 주소가 그 시 · 도로 시작하는 시험장만 남고 개수가 바뀐다
- 검색어를 넣으면 이름이나 주소에 그 말이 든 시험장만 남고, 없으면 "찾는 시험장이 없어요"가 보인다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 키 오류가 난다 |

- 파일 내려받기와 달리 자동변환 API는 활용신청을 해야 키로 부를 수 있다. 교육 전에 아래 시험 URL로 목록이 오는지 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://api.odcloud.kr/api/15076833/v1/uddi:94dbb45f-0644-40bf-a5d8-d96cfd26a26b
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | 공공데이터포털 인증키. 없으면 401 |
| `page` | | `1` | 페이지 번호 (기본 1) |
| `perPage` | | `300` | 한 번에 받을 행 수 (기본 **10**) — 218행을 한 번에 받으려면 300 |
| `returnType` | | `JSON` | 기본 JSON. `XML` 이면 XML |

시험 URL (브라우저, Encoding 키)

```
https://api.odcloud.kr/api/15076833/v1/uddi:94dbb45f-0644-40bf-a5d8-d96cfd26a26b?page=1&perPage=5&serviceKey=내_Encoding_키
```

## 응답에서 쓸 항목

목록은 `data` 에 있다. `totalCount` 는 전체 행 수.

| 항목 | 뜻 | 화면 |
|---|---|---|
| `시험장명` | 시험장 이름 | 카드 제목 |
| `주소` | 주소 | 카드 · 시 · 도 거르기 |
| `필기시험장 수` | 필기시험장 개수 (숫자) | "필기 3실" |
| `실기시험장 수` | 실기시험장 개수 (숫자) | "실기 1실" |
| `필기 가용인원 수` | 필기 수용 인원 (숫자) | 작은 글씨 |
| `실기 가용인원 수` | 실기 수용 인원 (숫자) | 작은 글씨 |

## 막히는 곳

- 항목 이름이 한글이고 띄어쓰기가 있다. 코드에서는 `item["필기시험장 수"]` 처럼 대괄호로 읽게 한다.
- `perPage` 를 빼면 10곳만 온다. "시험장이 10곳뿐"이면 이것부터 본다.
- 검색 조건 변수가 없다. 지역 거르기는 전부 받은 뒤 화면에서 한다.
- 판마다 요청 주소가 다르다(2021 · 2023 · 2025 · 2026 판). 이 카드의 주소는 2026-08-18 판이다. 2021 판은 항목 이름이 `시험장 명`(띄어 씀)이고 숫자가 글자로 온다.
- 주소의 시 · 도 이름이 섞여 있다 — `경기도` · `경기`, `전라북도` · `전북`, `부산광역시` · `부산`, `강원도` · `강원특별자치도` 처럼 첫 낱말이 30가지다. 시 · 도 목록은 짧은 이름(서울 · 부산 · 경기 …)으로 맞춰 만들게 하고, 만든 목록을 눈으로 확인한다.
- 필기시험장이 0인 곳이 79곳, 실기시험장이 0인 곳이 61곳이다. 0은 "필기 0실"로 쓰지 말고 숨긴다.
