# 우리 동네 전자파 노출지수

> 전자파 · 한국방송통신전파진흥원 의무측정무선국 전자파 노출지수 · 난이도 중

| 항목 | 내용 |
|---|---|
| 만드는 것 | 주소를 넣으면 그 주변(반경 300m) 무선국의 전자파 측정값과 노출지수를 가까운 순 카드로 보여 주는 한 화면 |
| API | [한국방송통신전파진흥원_의무측정무선국에 따른 전자파 노출지수(API)](https://www.data.go.kr/data/15125635/openapi.do) — 주소를 넣어 부르는 **REST 오픈API** |
| 승인 · 한도 | 개발계정 자동승인 · 하루 10,000회 |
| 응답 형식 | JSON (형식 지정 변수 없음) · 페이지 나눔 없이 반경 안 전부 (서울시청 300m 359줄 · 1km 4,148줄) |
| 미리 받은 데이터 | 시작 폴더 `data\07.json` — 서울특별시 중구 세종대로 110 반경 300m 356줄 (개인 시설자 3줄은 뺐다). `vibe-plan` 이 `data\snapshot.json` 으로 복사한다 |

이 파일이 **주제 카드**다. 시작 폴더(`C:\workspace\vibe`)의 `topics\` 에도 들어 있다. 1일차에는 `ego-browser` 로 위 API 페이지를 읽어 `api-notes.md` 를 만들고(조사), `vibe-plan 스킬로 주제 07 API 시험해줘` 로 5건만 불러 본 뒤(API 시험), 그 데이터로 `vibe-plan 스킬로 화면 구성 기획해줘` 를 한다.

## 교육 시간 안에 만드는 것

| 단계 | 할 일 |
|---|---|
| API 시험 | 주소 하나 · 반경 0.1km로 불러 앞 5건을 본다 — 숫자 칸이 숫자로 오는 것, 칸이 빠진 줄, 명세 설명과 다른 항목 |
| 데이터 연결 | `/api/data?address=…` 라우트가 받은 주소로 API를 부르게 하기 (`distance=0.3`). 주소가 없으면 서울특별시 중구 세종대로 110 |
| 화면 구성 → 디자인 입히기 | 무선국을 카드로 — 이름 · 통신사 · 거리 · 노출지수, 맨 위에 "반경 300m 안 N곳" → 실제 데이터 위에 디자인 |
| 기능 하나씩 | 주소 넣기 → 통신사 거르기 · 노출지수 높은 순 중 1개 |

완료 기준 예시

- 첫 화면에 서울시청 주변 무선국 카드가 가까운 순으로 보이고, 위에 "반경 300m 안 N곳"이 보인다
- 주소에 "전라남도 나주시 빛가람로 760"을 넣으면 그 주변 무선국으로 바뀐다
- 없는 주소를 넣으면 빈 화면이 아니라 "주소를 찾지 못했어요"가 보인다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://apis.data.go.kr/B552729/kcaApiService_emf/getEmfExposureIndex
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | 공공데이터포털 인증키 |
| `address` | ● | `서울특별시 중구 세종대로 110` | 찾을 주소 — 도로명 · 지번 · `나주시` 처럼 짧아도 된다 |
| `distance` | | `0.3` | 반경 km (기본 1) — 1km면 4,000줄이 넘으니 0.3으로 줄인다 |

시험 URL (브라우저, Encoding 키)

```
https://apis.data.go.kr/B552729/kcaApiService_emf/getEmfExposureIndex?serviceKey=내_Encoding_키&address=서울특별시 중구 세종대로 110&distance=0.1
```

## 응답에서 쓸 항목

목록은 `response.body.items.list` 에 있다. `response.body.totalCount` 는 줄 수, `response.body.lat` · `lon` 은 찾은 주소의 좌표. 명세는 모든 값을 글자(string)라 하지만 노출지수 · 측정값 · 거리 · 좌표는 숫자로 온다. **명세의 항목 설명이 한 칸씩 밀려 있다** — 아래 표는 실제로 온 값 기준이다.

| 항목 | 뜻 (실제 값) | 화면 |
|---|---|---|
| `callNm` | 무선국 이름 (예: `SKTL시청역3번출구-지MDRRU`) — 명세에는 "시설자" | 카드 제목 |
| `fcltyNm` | 통신사 — `SKT` · `KT` · `LGU+` · `기타` — 명세에는 "측정기관" | 꼬리표 · 거르기 |
| `distance` | 넣은 주소에서 거리 (km 숫자, 예: `0.121`) — 명세에 없다 | "121m" · 가까운 순 |
| `expsrIdexVal` | 전자파 노출지수 (예: `0.0000293`) — 대부분 (측정값 ÷ 기준값)² 이라 1이 기준과 같은 세기 | "기준의 0.003%" |
| `mesureVal` · `ermtwInStdrVal` | 측정값 · 인체보호 기준값 (숫자) | 작은 글씨 |
| `mesureDe` | 측정일 — `20161021` 같은 글자 (2007 ~ 2026년) | "2016. 10. 21." |
| `gisBassAdres` | 무선국 주소 | 작은 글씨 |
| `opertNm` | 측정기관 — `ITSELF`(자체) · `KCA` — 명세에는 "게시물 번호" | 작은 글씨 |
| `mesureRceptNo` | 측정접수번호 | 목록의 key (배열 위치를 붙인다) |
| `ownrNm` | 시설자명 — 개인은 `정*은` 처럼 가려져 온다 | 쓰지 않는다 |
| `levelVal` | 등급 `1` · `4` — 뜻이 명세에 없다 | 쓰지 않는다 |

## 막히는 곳

- 명세에 요청 변수가 없다. `address` · `distance` 로 부른다 — 둘 다 확인했다. `lat` · `lon` 만 넣으면 0줄이다.
- 페이지 나눔이 없다. `pageNo` · `numOfRows` 를 넣어도 반경 안 전부 온다 — 1km면 4,148줄(2MB). `distance=0.3` 으로 줄인다.
- 목록 경로가 `body.items.item` 이 아니라 `response.body.items.list` 다.
- 주소를 못 찾아도 오류가 아니다 — `resultCode` `00` · `totalCount` `0` · `lat` `0` 으로 온다. 0줄이면 "주소를 찾지 못했어요"를 보여 준다.
- 노출지수 · 측정값 칸이 아예 없는 줄이 있다(서울시청 300m 359줄 중 9줄). 없으면 "측정값 없음"으로 쓴다.
- 노출지수가 아주 작다(0.00000025 ~ 0.073). 100을 곱해 "기준의 몇 %"로 보여 준다.
- 같은 무선국 이름 · 같은 측정접수번호가 두 번 나오는 줄이 있다. 목록의 key는 측정접수번호에 배열 위치를 붙인다.
- 주소에 빈칸 · 한글이 있다. 라우트에서 `URLSearchParams` 로 붙여 인코딩한다. 브라우저 주소창에 그대로 넣으면 브라우저가 바꿔 준다.

## 향후 고도화 (교육 시간 밖 — 기록만)

- 지도에 무선국 점 찍기 — `rdostGpsLaVal` · `rdostGpsLoVal` 이 위도 · 경도다
- 반경 고르기 (100m · 300m · 500m)
- 내 위치로 찾기 — 위치를 주소로 바꾸는 별도 API가 필요하다
- 04 카드(전자파 용어사전)로 "노출지수" 같은 낱말 뜻풀이
