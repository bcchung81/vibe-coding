# 밤에 여는 소아과

> 육아 · 국립중앙의료원 병·의원 찾기 (달빛어린이병원) · 난이도 중

| 항목 | 내용 |
|---|---|
| 만드는 것 | 시도 · 시군구를 고르면 밤 · 휴일에도 진료하는 달빛어린이병원과 오늘 진료 시간을 보여 주는 한 화면 |
| API | [국립중앙의료원_전국 병·의원 찾기 서비스](https://www.data.go.kr/data/15000736/openapi.do) — "달빛어린이병원 및 소아전문센터 목록정보 조회" 기능 |
| 승인 · 한도 | 개발계정 자동승인 · **하루 1,000회** |
| 응답 형식 | **XML만** — 서버 라우트에서 JSON으로 바꾼다 |
| 강사가 미리 주는 것 | 시도 · 시군구 이름 목록, JSON으로 바꿔 둔 `snapshot.json` |

이 파일이 **주제 카드**다. 시작 폴더(`vibe.zip`)의 `topics\` 에도 들어 있다. 1일차 2교시 첫 명령은 `/vibe-prd 06` — 에이전트가 이 카드를 읽고 인터뷰를 시작한다.

## 교육 시간 안에 만드는 것

| 언제 | 할 일 |
|---|---|
| 1일차 3교시 (화면 30분) | 시도 · 시군구 고르기 → `snapshot.json` 의 병원을 카드로 보여 주고 오늘 요일의 진료 시간 표시 |
| 1일차 3교시 (실제 API 20분) | `/api/data` 라우트가 실제 API(XML)를 불러 JSON으로 바꿔 돌려주게 하기 |

완료 기준 예시

- 시군구를 고르면 병원 카드에 이름 · 주소 · 전화 · 오늘 진료 시간("08:30~23:00")이 보인다
- 병원이 없는 지역이면 "이 지역에는 달빛어린이병원이 없습니다"가 보인다
- 카드에 "방문 전 전화로 확인하세요"가 보인다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://apis.data.go.kr/B552657/HsptlAsembySearchService/getBabyListInfoInqire
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `ServiceKey` | ● | 내 키 | 이 API는 대문자 S |
| `Q0` | | `서울특별시` | 시도 (전체 이름) |
| `Q1` | | `강남구` | 시군구 |
| `numOfRows` | | `20` | |
| `pageNo` | | `1` | |

시험 URL (브라우저, Encoding 키)

```
https://apis.data.go.kr/B552657/HsptlAsembySearchService/getBabyListInfoInqire?ServiceKey=내_Encoding_키&Q0=서울특별시&Q1=강남구&numOfRows=20&pageNo=1
```

## 응답에서 쓸 항목

| 항목 | 뜻 | 화면 |
|---|---|---|
| `dutyName` | 기관명 | 카드 제목 |
| `dutyAddr` | 주소 | 작은 글씨 |
| `dutyTel1` | 대표전화 | 누르면 전화 |
| `dutyTime1s` ~ `dutyTime8s` | 진료 시작 시각 (1 월 … 7 일, 8 공휴일) | "0830" → "08:30" |
| `dutyTime1c` ~ `dutyTime8c` | 진료 끝 시각 | "2300" → "23:00" |
| `wgs84Lat` · `wgs84Lon` | 위도 · 경도 | 고도화(지도)에 쓴다 |

## 막히는 곳

- 응답이 XML뿐이다. 서버 라우트에서 XML을 JSON으로 바꾸게 시킨다 (라이브러리는 에이전트가 고른다).
- 병원이 없는 시군구가 많다. 빈 결과 화면을 먼저 만든다.
- 오늘 요일은 **한국 시간 기준**으로 계산하게 시킨다 (Vercel 서버 시계는 UTC). 공휴일 판별은 하지 않는다.
- 하루 1,000회라 같은 지역은 서버 라우트에서 잠시 캐시한다.
- 공개 정보가 실제와 다를 수 있다. "방문 전 전화 확인" 문구를 넣는다.
