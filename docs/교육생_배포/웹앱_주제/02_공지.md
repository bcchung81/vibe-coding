> 자격 · 한국방송통신전파진흥원 국가기술자격 공지사항 · 난이도 중

| 항목 | 내용 |
|---|---|
| 만드는 것 | 전파 · 무선설비 · 방송 · 통신 분야 국가기술자격 공지를 최신순으로 보여 주고, 제목을 누르면 내용과 첨부파일 이름이 펼쳐지는 한 화면 |
| API | [한국방송통신전파진흥원_국가기술자격 공지사항](https://www.data.go.kr/data/15125639/openapi.do) — 자격검정 홈페이지(cq.or.kr) 공지 |

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://apis.data.go.kr/B552729/kcaApiService_cq1/getCqNotice
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | 공공데이터포털 인증키 |
| `pageNo` | | `1` | 시작 페이지 |
| `numOfRows` | | `100` | 한 번에 받을 줄 수 — 공지 수가 아니라 첨부 줄 수 |

시험 URL (브라우저, Encoding 키)

```
https://apis.data.go.kr/B552729/kcaApiService_cq1/getCqNotice?serviceKey=내_Encoding_키&pageNo=1&numOfRows=5
```

## 응답에서 쓸 항목

목록은 `body.items.list` 에 있다. **공지 하나가 첨부파일마다 한 줄씩** 온다 — `inqireCo` 로 묶는다. 명세는 모든 값을 글자(string)라 하지만 `registDt` · `inqireCo` · `atchmnflSn` 은 숫자로 온다.

| 항목 | 뜻 | 화면 |
|---|---|---|
| `sj` | 게시물 제목 | 목록 |
| `registDt` | 등록 시각 — 1970년부터 센 밀리초 숫자 (예: `1791784818000`) | 한국 시간 날짜 "2026. 10. 12." |
| `bbscttCn` | 게시물 내용 — HTML | 펼침 (글자만) |
| `atchmnflNm` | 첨부파일 이름 — 줄마다 하나 | 펼침 아래 목록 |
| `atchmnflSn` | 첨부 순번 (1, 2, 3 …) — 개수가 아니다 | 첨부 목록 순서 |
| `inqireCo` | 게시물 번호 — 같은 공지의 줄은 같은 번호 | 묶는 기준 · 목록의 key |

## 막히는 곳

- 목록 경로가 `body.items.item` 이 아니라 `body.items.list` 다.
- 같은 공지가 여러 줄로 온다 (첨부 10개면 10줄). `inqireCo` 로 묶어 공지 하나로 만들고 첨부 이름은 목록으로 모은다. 같은 번호인데 등록 시각이 다른 줄도 있다 — 가장 늦은 시각을 쓴다.
- `registDt` 는 숫자(밀리초)다. 한국 시간(`Asia/Seoul`)으로 날짜를 만든다.
- `bbscttCn` 은 HTML이다. 화면에 HTML로 넣지 말고 태그를 빼고 글자만 보여 주게 한다 — 남이 쓴 HTML을 그대로 넣으면 보안 문제가 된다.
- 첨부파일 내려받기 주소는 명세에 없다. 원문은 자격검정 홈페이지(cq.or.kr)로 가는 링크 하나로 대신한다.
- 검색 변수가 없다. 받은 줄 안에서 거른다.
