## 교육 시간 안에 만드는 것

| 단계 | 할 일 |
|---|---|
| API 시험 | 5건만 불러 본다 — `정렬` 이 초성(ㄱ · ㄴ …)인 것, 비어 있는 칸(`null`), 용어명에 한자 · 번호가 붙은 것 |
| 데이터 연결 | `/api/data` 라우트가 자동변환 API를 한 번 불러 699행 전체를 돌려주게 하기 (`perPage=700`) |

완료 기준 예시

- 첫 화면에 용어 카드가 뜻 · 출처와 함께 보이고, 위에 "전체 699개"가 보인다
- ㄱ 버튼을 누르면 ㄱ으로 시작하는 용어만 남고 개수가 바뀐다
- 검색어를 넣으면 용어명이나 설명에 그 말이 든 용어만 남고, 없으면 "찾는 용어가 없어요"가 보인다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 키 오류가 난다 |

- 파일 내려받기와 달리 자동변환 API는 활용신청을 해야 키로 부를 수 있다. 교육 전에 아래 시험 URL로 목록이 오는지 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://api.odcloud.kr/api/15076842/v1/uddi:7cac43f5-47ba-4697-a61f-cea0357f3efe
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | 공공데이터포털 인증키. 없으면 401 |
| `page` | | `1` | 페이지 번호 (기본 1) |
| `perPage` | | `700` | 한 번에 받을 행 수 (기본 **10**) — 699행을 한 번에 받으려면 700 |
| `returnType` | | `JSON` | 기본 JSON. `XML` 이면 XML |

시험 URL (브라우저, Encoding 키)

```
https://api.odcloud.kr/api/15076842/v1/uddi:7cac43f5-47ba-4697-a61f-cea0357f3efe?page=1&perPage=5&serviceKey=내_Encoding_키
```

## 응답에서 쓸 항목

목록은 `data` 에 있다. `totalCount` 는 전체 행 수.

| 항목 | 뜻 | 화면 |
|---|---|---|
| `용어명` | 용어 — 한자 · 괄호가 붙기도 한다 (예: `항상성(恒常性)`) | 카드 제목 · 검색 |
| `설명` | 뜻풀이 (가장 긴 것 558자) | 카드 본문 · 검색 |
| `출처` | 출처 — 사전 이름이나 주소 (예: `Mosby's Medical Dictionary`, `http://en.wikipedia.org/`) | 작은 글씨 |
| `정렬` | 첫 글자 초성 — ㄱ ~ ㅎ 14개. 3행은 `null` | 초성 버튼 |
| `등록일자` · `수정일자` | 모두 `2020-05-30 05:12` 하나 | 쓰지 않는다 |

## 막히는 곳

- 항목 이름이 한글이다. 코드에서는 `item["용어명"]` 처럼 대괄호로 읽게 한다.
- `perPage` 를 빼면 10개만 온다. "용어가 10개뿐"이면 이것부터 본다.
- 판이 두 개다(2021-01-29 · 2023-07-25). 이 카드의 주소는 2023-07-25 판이다.
- `정렬` 이 `null` 인 3행은 초성 버튼에서 빠진다. "기타" 버튼에 모으거나 `용어명` 첫 글자로 초성을 다시 구한다.
- 용어명이 같은 행이 4쌍 있다(`식도` · `접촉 전류` 등). 목록의 key는 용어명만 쓰지 말고 배열 위치를 붙인다.
- 출처가 주소(`http://…`)인 행이 있다. 링크로 보여 주거나 글자 그대로 둔다. 같은 사전도 표기가 조금씩 다르다(`Mosby's` · `Mosby’s`) — 출처로 거르기는 넣지 않는다.
- 검색 조건 변수가 없다. 전부 받은 뒤 화면에서 거른다.
