완료 기준 예시

- 첫 화면에 과제명 · 전담기관 · 사업비 · 사업기간 표가 보이고, 위에 "전체 N건"과 "2021~2023년 사업"이 보인다
- 사업비순을 누르면 큰 금액이 위로 오고, 금액이 "37억 5,500만 원"처럼 읽기 쉽게 보인다
- 전담기관을 고르면 그 기관 과제만 남고, 과제명 검색과 함께 쓸 수 있다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 키 오류가 난다 |

- 파일 내려받기와 달리 자동변환 API는 활용신청을 해야 키로 부를 수 있다. 교육 전에 아래 시험 URL로 목록이 오는지 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://api.odcloud.kr/api/15133304/v1/uddi:427e5fb9-3498-4ae9-8841-ab72a7cea63d
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | 공공데이터포털 인증키. 없으면 401 |
| `page` | | `1` | 페이지 번호 (기본 1) |
| `perPage` | | `500` | 한 번에 받을 행 수 (기본 **10**) — 486행을 한 번에 받으려면 500 |
| `returnType` | | `JSON` | 기본 JSON. `XML` 이면 XML |

시험 URL (브라우저, Encoding 키)

```
https://api.odcloud.kr/api/15133304/v1/uddi:427e5fb9-3498-4ae9-8841-ab72a7cea63d?page=1&perPage=5&serviceKey=내_Encoding_키
```

## 응답에서 쓸 항목

목록은 `data` 에 있다. `totalCount` 는 전체 행 수.

| 항목 | 뜻 | 화면 |
|---|---|---|
| `과제명` | 과제 이름 | 표 첫 칸 · 검색 |
| `전담기관명` | 전담기관 (21곳) | 표 · 거르기 |
| `사업비` | 사업비 — 원 단위 숫자 (3천만 ~ 5,797억) | 억 · 만 원 · 정렬 |
| `사업시작일자` · `사업종료일자` | 사업기간 — `2021-01-01` 같은 글자 | "2022.4 ~ 2022.12" |
| `과제코드` | 과제 코드 | 목록의 key |

## 막히는 곳

- 항목 이름이 한글이다. 코드에서는 `item["사업비"]` 처럼 대괄호로 읽게 한다.
- `perPage` 를 빼면 10건만 온다. "사업이 10건뿐"이면 이것부터 본다.
- 사업비 단위는 명세에 없다. 값 크기(한 해 과제 3,755,000,000 등)로 보아 **원** 단위다. "37억 5,500만 원"처럼 억 · 만으로 바꿔 보여 준다.
- 전담기관 거르기 목록은 미리 정하지 말고 데이터에서 뽑는다 (21곳).
- 2023년까지의 1회성 데이터다. "지금 진행 중" 같은 표시는 넣지 않는다.
