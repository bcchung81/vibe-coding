# 이번 주말 축제

> 여가 · 한국관광공사 국문 관광정보 · 난이도 하

| 항목 | 내용 |
|---|---|
| 만드는 것 | 시도를 고르면 이번 주말에 열리는 축제 · 행사를 사진 · 기간과 함께 보여 주는 한 화면 |
| API | [한국관광공사_국문 관광정보 서비스_GW](https://www.data.go.kr/data/15101578/openapi.do) — "행사정보조회" 기능 |
| 승인 · 한도 | 개발계정 자동승인 · **하루 1,000회** |
| 응답 형식 | JSON (`_type=json`, 빼면 XML) |
| 강사가 미리 주는 것 | 법정동 시도코드 표(법정동코드조회 결과), `snapshot.json` |

이 파일이 **주제 카드**다. 시작 폴더(`vibe.zip`)의 `topics\` 에도 들어 있다. 1일차 2교시 첫 명령은 `/vibe-prd 08` — 에이전트가 이 카드를 읽고 인터뷰를 시작한다.

## 교육 시간 안에 만드는 것

| 언제 | 할 일 |
|---|---|
| 1일차 3교시 (화면 30분) | 시도 고르기 → `snapshot.json` 에서 이번 주말에 걸치는 행사만 골라 사진 카드로 보여 주기 |
| 1일차 3교시 (실제 API 20분) | `/api/data` 라우트가 스냅샷 대신 실제 API를 부르게 바꾸기 |

완료 기준 예시

- 시도를 고르면 행사 카드에 사진 · 이름 · 기간 · 주소가 보인다
- 이번 주말(토 · 일)에 열리지 않는 행사는 보이지 않는다
- 사진 아래에 출처 "한국관광공사"가 보인다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://apis.data.go.kr/B551011/KorService2/searchFestival2
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | |
| `MobileOS` | ● | `WEB` | 고정값 |
| `MobileApp` | ● | `weekendfestival` | 내 앱 이름 (영문) |
| `eventStartDate` | ● | `20261031` | 행사 시작일 기준 (YYYYMMDD) |
| `eventEndDate` | | `20261101` | 행사 종료일 |
| `lDongRegnCd` | | `11` | 법정동 시도코드 (예시는 서울) |
| `arrange` | | `C` | 정렬 — A 제목순 · C 수정일순 · D 생성일순 |
| `_type` | | `json` | |
| `numOfRows` · `pageNo` | | `30` · `1` | |

시험 URL (브라우저, Encoding 키)

```
https://apis.data.go.kr/B551011/KorService2/searchFestival2?serviceKey=내_Encoding_키&MobileOS=WEB&MobileApp=weekendfestival&_type=json&eventStartDate=20261031&lDongRegnCd=11&numOfRows=30&pageNo=1
```

## 응답에서 쓸 항목

| 항목 | 뜻 | 화면 |
|---|---|---|
| `title` | 행사 이름 | 카드 제목 |
| `eventstartdate` · `eventenddate` | 시작 · 종료일 (YYYYMMDD) | "10.31 ~ 11.2" |
| `addr1` | 주소 | 작은 글씨 |
| `firstimage` · `firstimage2` | 대표 이미지 (원본 · 썸네일) | 카드 사진 — 목록에는 썸네일 |
| `tel` | 전화번호 | 표시 |
| `cpyrhtDivCd` | 이미지 저작권 유형 (Type1 · Type3) | 출처 표시 |
| `progresstype` | 취소 · 연기 같은 진행 상태 | 있으면 배지 |

## 막히는 곳

- `MobileOS` · `MobileApp` 이 빠지면 오류가 난다.
- `areaCode` · `sigunguCode` 는 **삭제 예정**이다. 지역은 법정동 코드(`lDongRegnCd`)로 거른다. 옛 예시(`KorService1` · `areaCode`)를 따라가지 않는다.
- 받은 목록에서 이번 주말에 걸치는 행사만 시작 · 종료일로 한 번 더 거르게 시킨다. 주말 날짜는 **한국 시간 기준**으로 계산한다 (Vercel 서버 시계는 UTC).
- 이미지가 없는 행사가 있다. 빈 자리 그림을 넣는다.
- 이미지는 저작권 유형에 맞게 출처("한국관광공사")를 표시하고, Type3은 변경(자르기 · 덧칠) 없이 쓴다.
- 하루 1,000회라 같은 조건은 서버 라우트에서 잠시 캐시한다.

## 향후 고도화 (교육 시간 밖 — 기록만)

- 지도에 표시 — `mapx` · `mapy` 좌표
- 행사 상세(소개 · 요금 · 홈페이지) — `detailCommon2` · `detailIntro2` 기능 (행사마다 호출이 늘어난다)
- 내 위치 근처 — `locationBasedList2` 기능 + 위치 권한
- 반려동물 동반 여부 — `detailPetTour2` 기능
