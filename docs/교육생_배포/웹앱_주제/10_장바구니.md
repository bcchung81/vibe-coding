# 오늘 장바구니 시세

> 장보기 · aT 기간별 소매가격 · 난이도 중

| 항목 | 내용 |
|---|---|
| 만드는 것 | 품목을 고르면 최근 며칠 소매가격과 지역 · 시장별 차이를 표로 보여 주는 한 화면 |
| API | [한국농수산식품유통공사_기간별 소매가격 정보 조회](https://www.data.go.kr/data/15156065/openapi.do) |
| 승인 · 한도 | 개발계정 자동승인 · 하루 10,000회 |
| 응답 형식 | JSON (`returnType=json`) |
| 강사가 미리 주는 것 | 품목코드 표(참고문서 "기간별 소매가격 정보_코드.xlsx"에서 뽑음), `snapshot.json` |

이 파일이 **주제 카드**다. 시작 폴더(`vibe.zip`)의 `topics\` 에도 들어 있다. 1일차 2교시 첫 명령은 `/vibe-prd 10` — 에이전트가 이 카드를 읽고 인터뷰를 시작한다.

## 교육 시간 안에 만드는 것

| 언제 | 할 일 |
|---|---|
| 1일차 3교시 (화면 30분) | 품목 고르기 → `snapshot.json` 의 가격을 날짜 · 지역별 표로 보여 주기 |
| 1일차 3교시 (실제 API 20분) | `/api/data` 라우트가 스냅샷 대신 실제 API를 부르게 바꾸기 |

완료 기준 예시

- 품목을 고르면 최근 5일의 날짜 · 지역 · 시장 · 가격 · 단위 표가 보인다
- 가장 싼 곳과 비싼 곳이 눈에 띄게 표시된다
- 조사가 없는 날(주말 등)이 있어도 표가 깨지지 않는다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://apis.data.go.kr/B552845/periodRetail/price
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | |
| `pageNo` | ● | `1` | |
| `numOfRows` | ● | `100` | 최대 1,000 |
| `returnType` | ● | `json` | |
| `cond[exmn_ymd::GTE]` | ● | `20261019` | 조사일자 — 이날부터 |
| `cond[exmn_ymd::LTE]` | ● | `20261023` | 조사일자 — 이날까지 |
| `cond[item_cd::EQ]` | | 품목코드 | 코드표에서 고른다 |
| `cond[sgg_cd::EQ]` | | 시군구코드 | 지역 좁히기 |

시험 URL (브라우저, Encoding 키 · 대괄호는 브라우저가 알아서 바꾼다)

```
https://apis.data.go.kr/B552845/periodRetail/price?serviceKey=내_Encoding_키&pageNo=1&numOfRows=100&returnType=json&cond[exmn_ymd::GTE]=20261019&cond[exmn_ymd::LTE]=20261023
```

## 응답에서 쓸 항목

| 항목 | 뜻 | 화면 |
|---|---|---|
| `exmn_ymd` | 조사일자 | 표 첫 칸 |
| `item_nm` · `vrty_nm` | 품목 · 품종명 | 제목 |
| `grd_nm` | 등급명 | 작은 글씨 |
| `sgg_nm` · `mrkt_nm` | 지역 · 시장명 | 표 |
| `exmn_dd_prc` | 조사일 가격 | 원 |
| `unit` · `unit_sz` | 단위 · 단위 크기 | "1kg" |
| `exmn_dd_cnvs_prc` | kg 환산 가격 | 비교용 |

## 막히는 곳

- 파라미터 이름에 대괄호(`cond[...]`)가 있다. 손으로 이어 붙이면 깨지니 코드에서는 `URLSearchParams` 로 조립하게 시킨다.
- 품목 · 지역이 숫자 코드라 코드표가 필요하다. 첫 화면은 강사가 준 품목 몇 개만 고르게 한다.
- 같은 품목이 시장 · 등급별로 여러 줄 온다. 평균을 낼지 하나만 보일지 PRD에서 정한다.
- 주말 · 공휴일은 조사가 없을 수 있다. 날짜는 **한국 시간 기준**으로 계산한다 (Vercel 서버 시계는 UTC).
