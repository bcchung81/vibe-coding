# 새 가족 찾기

> 반려동물 · 농림축산검역본부 구조동물 조회 · 난이도 하

| 항목 | 내용 |
|---|---|
| 만드는 것 | 시도와 개 · 고양이를 고르면 입양 공고 중인 구조동물을 사진 카드로 보여 주는 한 화면 |
| API | [농림축산검역본부_국가동물보호정보시스템 구조동물 조회 서비스](https://www.data.go.kr/data/15098931/openapi.do) |
| 승인 · 한도 | 개발계정 자동승인 · 하루 10,000회 |
| 응답 형식 | JSON (`_type=json`, 빼면 XML) |
| 강사가 미리 주는 것 | 시도 코드표(시도 조회 결과), `snapshot.json` |

이 파일이 **주제 카드**다. 시작 폴더(`vibe.zip`)의 `topics\` 에도 들어 있다. 1일차 2교시 첫 명령은 `/vibe-prd 07` — 에이전트가 이 카드를 읽고 인터뷰를 시작한다.

## 교육 시간 안에 만드는 것

| 언제 | 할 일 |
|---|---|
| 1일차 3교시 (화면 30분) | 시도 · 축종(개/고양이) 고르기 → `snapshot.json` 의 동물을 사진 카드로 보여 주기 |
| 1일차 3교시 (실제 API 20분) | `/api/data` 라우트가 스냅샷 대신 실제 API를 부르게 바꾸기 |

완료 기준 예시

- 시도와 "개"를 고르면 사진 · 품종 · 나이 · 성별 · 보호소 이름이 있는 카드가 보인다
- 사진이 없거나 깨지면 빈 자리 그림이 보이고 화면은 깨지지 않는다
- 카드에 공고 마감일과 보호소 전화번호가 보인다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소 (v2)

```
https://apis.data.go.kr/1543061/abandonmentPublicService_v2/abandonmentPublic_v2
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | |
| `upr_cd` | | 시도코드 | 시도 조회(`sido_v2`)로 받은 코드 — 강사가 표로 준다 |
| `upkind` | | `417000` | 축종 — 개 `417000` · 고양이 `422400` |
| `state` | | `notice` | 상태 — 공고중 `notice` |
| `_type` | | `json` | |
| `numOfRows` | | `20` | 1,000 이하 |
| `pageNo` | | `1` | |

시험 URL (브라우저, Encoding 키)

```
https://apis.data.go.kr/1543061/abandonmentPublicService_v2/abandonmentPublic_v2?serviceKey=내_Encoding_키&upkind=417000&state=notice&_type=json&numOfRows=20&pageNo=1
```

| `specialMark` | 특징 | 본문 |
| `careNm` · `careTel` | 보호소 이름 · 전화 | 카드 아래 |
| `noticeEdt` | 공고 종료일 | "~10/31까지" |

## 막히는 곳

- 주소가 **v2**로 바뀌었다(`abandonmentPublicService_v2`). 옛 블로그 예시(`abandonmentPublicSrvc`)를 따라가면 오류가 난다.
- 사진 주소가 `http://` 로 오면 배포한 `https` 사이트에서 막힐 수 있다. 리허설에서 확인하고, 안 되면 빈 자리 그림으로 대신한다.
- 시군구 · 보호소까지 고르려면 코드 조회가 두 단계 더 필요하다 — 교육에서는 시도까지만.
- 실제 동물 사진과 보호소 정보라 공고 내용을 바꾸거나 꾸며 쓰지 않는다.
