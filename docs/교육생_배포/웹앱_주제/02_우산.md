# 우산 챙겨?

> 날씨 · 기상청 단기예보 · 난이도 중

| 항목 | 내용 |
|---|---|
| 만드는 것 | 지역을 고르면 오늘 · 내일 시간대별 비 올 확률과 기온을 보여 주고 "우산 챙겨요 / 안 챙겨도 돼요"를 크게 말해 주는 한 화면 |
| API | [기상청_단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do) |
| 승인 · 한도 | 개발계정 자동승인 · 하루 10,000회 |
| 응답 형식 | JSON (`dataType=JSON`, 빼면 XML) |
| 강사가 미리 주는 것 | 지역별 격자 좌표(`nx` · `ny`) 표, `snapshot.json` |

이 파일이 **주제 카드**다. 시작 폴더(`vibe.zip`)의 `topics\` 에도 들어 있다. 1일차 2교시 첫 명령은 `/vibe-prd 02` — 에이전트가 이 카드를 읽고 인터뷰를 시작한다.

## 교육 시간 안에 만드는 것

| 언제 | 할 일 |
|---|---|
| 1일차 3교시 (화면 30분) | 지역 고르기 → `snapshot.json` 을 시간대별 표(기온 · 강수확률)로 보여 주고, 기준을 넘으면 우산 문구 |
| 1일차 3교시 (실제 API 20분) | `/api/data` 라우트가 스냅샷 대신 실제 API를 부르게 바꾸기 |

완료 기준 예시

- 지역을 고르면 시간대별 기온 · 강수확률 표가 보인다
- 오늘 강수확률이 기준(예: 60%)을 넘는 시간이 있으면 "우산 챙겨요"가 보인다 — 기준은 PRD에서 정한다
- 호출이 실패하면 스냅샷이 대신 보이고 "예시 데이터"라고 표시된다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소 (단기예보조회)

```
https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0/getVilageFcst
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `ServiceKey` | ● | 내 키 | 이 API는 대문자 S |
| `pageNo` | ● | `1` | |
| `numOfRows` | ● | `1000` | 하루치가 수백 줄이라 넉넉히 |
| `dataType` | | `JSON` | |
| `base_date` | ● | `20261025` | 발표 날짜 |
| `base_time` | ● | `0500` | 발표 시각 — 02 · 05 · 08 · 11 · 14 · 17 · 20 · 23시, 하루 8번 |
| `nx` · `ny` | ● | `60` · `127` | 예보 격자 좌표 (예시는 서울) |

시험 URL (브라우저, Encoding 키 · 날짜는 오늘로)

```
https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0/getVilageFcst?ServiceKey=내_Encoding_키&pageNo=1&numOfRows=1000&dataType=JSON&base_date=20261025&base_time=0500&nx=60&ny=127
```

## 응답에서 쓸 항목

한 줄에 값 하나가 온다: `fcstDate` · `fcstTime` (예보 날짜 · 시각), `category` (무슨 값), `fcstValue` (값).

| `category` | 뜻 | 값 |
|---|---|---|
| `POP` | 강수확률 | % |
| `PTY` | 강수형태 | 0 없음 · 1 비 · 2 비/눈 · 3 눈 · 4 소나기 |
| `SKY` | 하늘상태 | 1 맑음 · 3 구름많음 · 4 흐림 |
| `TMP` | 1시간 기온 | ℃ |
| `PCP` | 1시간 강수량 | "강수없음" 같은 글자로 온다 |
| `TMN` · `TMX` | 아침 최저 · 낮 최고 기온 | ℃ |

## 막히는 곳

- 값이 `category` 별로 한 줄씩 따로 온다. `fcstDate` + `fcstTime` 으로 묶어 시간대별 한 줄로 만들게 시킨다.
- `base_time` 은 하루 8번만 있다. 지금 시각에서 가장 최근 발표 시각을 계산해야 하고, 발표 직후 몇 분은 아직 없을 수 있어 한 단계 전 발표로 물러서게 한다.
- Vercel 서버 시계는 한국 시간이 아니다(UTC). 날짜 · 시각은 **한국 시간 기준**으로 계산하라고 시킨다.
- 활용가이드 최신판 예시는 다른 주소(`apihub.kma.go.kr`)를 쓴다. 그대로 따라가면 공공데이터포털 키로는 오류가 난다 — 주소는 위 요청 주소로 고정한다.
