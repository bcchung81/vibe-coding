## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 키 오류가 난다 |

- 파일 내려받기와 달리 자동변환 API는 활용신청을 해야 키로 부를 수 있다. 교육 전에 아래 시험 URL로 목록이 오는지 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://api.odcloud.kr/api/15076832/v1/uddi:47017b60-75a9-4936-8c22-da637675eaf2
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | 공공데이터포털 인증키. 없으면 401 |
| `page` | | `1` | 페이지 번호 (기본 1) |
| `perPage` | | `2000` | 한 번에 받을 행 수 (기본 **10**) — 1,616행을 한 번에 받으려면 2000 |
| `returnType` | | `JSON` | 기본 JSON. `XML` 이면 XML |

시험 URL (브라우저, Encoding 키)

```
https://api.odcloud.kr/api/15076832/v1/uddi:47017b60-75a9-4936-8c22-da637675eaf2?page=1&perPage=5&serviceKey=내_Encoding_키
```

## 응답에서 쓸 항목

목록은 `data` 에 있다. `totalCount` 는 전체 행 수.

| 항목 | 뜻 | 화면 |
|---|---|---|
| `응시종목` | 종목 11개 — 여러 종목을 묶은 이름도 있다 (예: `필기(기사/기능사/무선통신사)`) | 표 · 종목 고르기 |
| `필기실기` | `필기`(1,384행) · `실기`(232행) | 표 · 거르기 |
| `시험일시` | 시험 날짜 · 시각 — `2025-01-10 09:00` 같은 글자 | "1월 10일(금) 09:00" · 월별 묶기 |
| `시험장이름` | 시험장 104곳 (예: `CBT(서울01) 송파구` · `온라인교육`) | 표 |
| `응시인원` | 응시한 사람 수 (숫자) | 표 · 합계 |
| `검정년도` · `검정회차` | 연도(모두 2025) · 회차 (숫자) | 작은 글씨 |
| `제한인원` · `결시인원` · `응시율` | 정원 · 결시 · 응시율 — 아래 "막히는 곳" 참고 | 쓰지 않는다 |

## 막히는 곳

- 항목 이름이 한글이다. 코드에서는 `item["응시인원"]` 처럼 대괄호로 읽게 한다.
- `perPage` 를 빼면 10행만 온다. "시험이 10회뿐"이면 이것부터 본다.
- `응시율` 이 100을 넘는 행이 1,009개고, 그 행들은 `결시인원` 이 음수다 (예: 제한 60 · 응시 77 · 결시 -17). 값은 모두 응시인원 ÷ 제한인원으로 계산돼 있다. 상시 CBT 시험장에서 정원보다 많이 본 것으로 보인다(추정). 응시율 · 결시인원은 화면에 쓰지 않고 응시인원만 쓴다.
- `응시율` 은 숫자가 아니라 글자다. 쓰게 되면 숫자로 바꾼 뒤 정렬한다.
- `필기(기사/기능사/무선통신사)` 가 1,192행이다. 개별 종목이 아니라 여러 종목을 함께 보는 필기시험 이름이다 — 종목 목록에 그대로 둔다.
- 응시인원이 0인 행이 16개다. 숨기지 말고 0으로 보여 준다.
- 판마다 요청 주소가 다르다(2021 · 2022 · 2023 · 2024 · 2025 판). 이 카드의 주소는 2025년 시험(2025-12-31 판)이다.
