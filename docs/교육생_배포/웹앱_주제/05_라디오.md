# 우리 지역 라디오 주파수

> 방송 · 한국방송통신전파진흥원 라디오 방송채널 주파수 · 난이도 하

| 항목 | 내용 |
|---|---|
| 만드는 것 | 시 · 도와 시 · 군 · 구를 고르면 그 지역에서 들을 수 있는 라디오 채널과 주파수("FM 89.1 MHz")를 보여 주는 한 화면 |
| API | [한국방송통신전파진흥원_라디오 방송채널 주파수](https://www.data.go.kr/data/15173356/fileData.do) — 파일데이터(CSV)를 포털이 바꿔 주는 **자동변환 오픈API** |
| 승인 · 한도 | 자동승인 — 신청 직후 바로 불렸다(2026-11-08). 하루 한도는 페이지에 없다 |
| 응답 형식 | JSON (기본) · 전체 2,792행 · 1회성 데이터 (이 카드는 2026-10-19 판) |
| 미리 받은 데이터 | 시작 폴더 `data\05.json` — 2,792행 전체. `vibe-plan` 이 `data\snapshot.json` 으로 복사한다 |

이 파일이 **주제 카드**다. 시작 폴더(`C:\workspace\vibe`)의 `topics\` 에도 들어 있다. 1일차에는 `ego-browser` 로 위 API 페이지의 오픈API 명세를 읽어 `api-notes.md` 를 만들고(조사), `vibe-plan 스킬로 주제 05 API 시험해줘` 로 5건만 불러 본 뒤(API 시험), 그 데이터로 `vibe-plan 스킬로 화면 구성 기획해줘` 를 한다.

## 교육 시간 안에 만드는 것

| 단계 | 할 일 |
|---|---|
| API 시험 | 5건만 불러 본다 — `방송주파수` 가 Hz 숫자인 것(`711000` = 711 kHz), `방송구역코드` 가 10자리 숫자인 것, 경도 · 위도가 글자인 것 |
| 데이터 연결 | `/api/data` 라우트가 자동변환 API를 한 번 불러 2,792행 전체를 돌려주게 하기 (`perPage=3000`) |
| 화면 구성 → 디자인 입히기 | 채널을 카드로 — 채널 이름 · 주파수 · FM/AM, 맨 위에 "○○에서 N개 채널" → 실제 데이터 위에 디자인 |
| 기능 하나씩 | 시 · 도 고르기 → 시 · 군 · 구 고르기 → FM · AM 거르기 |

완료 기준 예시

- 첫 화면에 서울특별시 채널 28개가 주파수와 함께 보이고, 위에 "서울특별시에서 28개 채널"이 보인다
- 경기 → 수원시 영통구처럼 고르면 그 구역 채널만 남고 개수가 바뀐다
- 주파수가 `95300000` 이 아니라 "FM 95.3 MHz", `711000` 이 아니라 "AM 711 kHz"로 보인다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 키 오류가 난다 |

- 파일 내려받기와 달리 자동변환 API는 활용신청을 해야 키로 부를 수 있다. 교육 전에 아래 시험 URL로 목록이 오는지 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://api.odcloud.kr/api/15173356/v1/uddi:55ffec24-8faf-4240-be8a-9f7a0c4b900f
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | 공공데이터포털 인증키. 없으면 401 |
| `page` | | `1` | 페이지 번호 (기본 1) |
| `perPage` | | `3000` | 한 번에 받을 행 수 (기본 **10**) — 2,792행을 한 번에 받으려면 3000 |
| `returnType` | | `JSON` | 기본 JSON. `XML` 이면 XML |

시험 URL (브라우저, Encoding 키)

```
https://api.odcloud.kr/api/15173356/v1/uddi:55ffec24-8faf-4240-be8a-9f7a0c4b900f?page=1&perPage=5&serviceKey=내_Encoding_키
```

## 응답에서 쓸 항목

목록은 `data` 에 있다. `totalCount` 는 전체 행 수.

| 항목 | 뜻 | 화면 |
|---|---|---|
| `방송구역` | 들을 수 있는 구역 — 시 · 군 · 구 이름 181개 (예: `수원시 영통구` · `가평군`). 특별 · 광역시는 `서울특별시` 하나 | 시 · 군 · 구 고르기 |
| `방송구역코드` | 구역 코드 — 10자리 숫자 (예: `1100000000`). 앞 두 자리가 시 · 도 | 시 · 도 고르기 |
| `서비스채널` | 채널 이름 45개 (예: `KBS 제1FM` · `MBC FM4U`) | 카드 제목 |
| `방송주파수` | 주파수 — **Hz** 숫자 (FM `95300000` · AM `711000`) | "FM 95.3 MHz" · "AM 711 kHz" |
| `서비스` | `FM`(2,048행) · `AM`(744행) | FM · AM 거르기 |
| `경도` · `위도` | 구역 좌표 — 글자 (예: `"126.9392"`) | 쓰지 않는다 (고도화 지도용) |
| `방송구분` | `1` · `2` — 뜻이 명세에 없다 | 쓰지 않는다 |

## 막히는 곳

- 항목 이름이 한글이다. 코드에서는 `item["서비스채널"]` 처럼 대괄호로 읽게 한다.
- `perPage` 를 빼면 10행만 온다. "채널이 10개뿐"이면 이것부터 본다.
- 시 · 도 이름 칸이 없다. `방송구역코드` 앞 두 자리로 만든다 — 11 서울 · 26 부산 · 27 대구 · 28 인천 · 29 광주 · 30 대전 · 31 울산 · 41 경기 · 42 강원 · 43 충북 · 44 충남 · 45 전북 · 46 전남 · 47 경북 · 48 경남 · 50 제주. 세종은 없다. 코드는 숫자로 오니 글자로 바꾼 뒤 앞 두 자리를 자른다.
- 경기는 1,068행이다. 시 · 도만 고르면 너무 많으니 시 · 군 · 구까지 고르게 한다.
- 같은 구역에 같은 채널이 주파수만 다르게 두 번 이상 나온다(95행). 주파수마다 따로 보여 준다. 모든 칸이 같은 행도 4개 있다 — 목록의 key는 배열 위치를 붙인다.
- 주파수는 Hz다. FM은 1,000,000으로 나눠 MHz, AM은 1,000으로 나눠 kHz로 보여 준다.
- 응답이 약 750KB다. 화면은 라우트에서 한 번만 받아 쓰고, 고를 때마다 다시 부르지 않는다.

## 향후 고도화 (교육 시간 밖 — 기록만)

- 지도에 구역 표시 — `경도` · `위도` 가 이미 있다
- 채널 이름으로 찾기 — 전국에서 "MBC FM4U" 주파수 모아 보기
- 내 위치에서 가까운 구역 자동 선택
- 오픈API "라디오 채널 정보"(위치로 조회) — 전파누리(spectrummap.kr)에서 키를 따로 받는다
