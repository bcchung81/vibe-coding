# 버스 몇 분?

> 출퇴근 · 국토교통부 TAGO 버스도착정보 · 난이도 중

| 항목 | 내용 |
|---|---|
| 만드는 것 | 자주 타는 정류소를 고르면 곧 올 버스와 남은 시간을 보여 주는 한 화면 |
| API | [국토교통부_(TAGO)_버스도착정보](https://www.data.go.kr/data/15098530/openapi.do) |
| 승인 · 한도 | 개발계정 자동승인 · 하루 10,000회 |
| 응답 형식 | JSON (`_type=json`, 빼면 XML) |
| 강사가 미리 주는 것 | 도시코드 · 정류소 ID(`nodeId`) 목록, `snapshot.json` |

이 파일이 **주제 카드**다. 시작 폴더(`vibe.zip`)의 `topics\` 에도 들어 있다. 1일차 2교시 첫 명령은 `/vibe-prd 01` — 에이전트가 이 카드를 읽고 인터뷰를 시작한다.

## 교육 시간 안에 만드는 것

| 언제 | 할 일 |
|---|---|
| 1일차 3교시 (화면 30분) | 정류소 목록에서 하나 고르기 → `snapshot.json` 의 도착 정보를 남은 시간 짧은 순 카드로 보여 주기 |
| 1일차 3교시 (실제 API 20분) | `/api/data` 라우트가 스냅샷 대신 실제 API를 부르게 바꾸기 |

완료 기준 예시

- 정류소를 고르면 버스 카드가 남은 시간 짧은 순으로 보인다
- 남은 시간이 "13분 36초"처럼 보인다 (`arrtime` 은 초 단위)
- 도착 예정 버스가 없으면 "지금 도착 예정 버스가 없습니다"가 보인다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://apis.data.go.kr/1613000/ArvlInfoInqireService/getSttnAcctoArvlPrearngeInfoList
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | ● | 내 키 | 서버 라우트에서만 읽는다 |
| `cityCode` | ● | `25` | 도시코드 (예시는 대전) |
| `nodeId` | ● | `DJB8001793` | 정류소 ID |
| `_type` | | `json` | |
| `numOfRows` | | `20` | 한 번에 받을 건수 |

시험 URL (브라우저, Encoding 키)

```
https://apis.data.go.kr/1613000/ArvlInfoInqireService/getSttnAcctoArvlPrearngeInfoList?serviceKey=내_Encoding_키&cityCode=25&nodeId=DJB8001793&_type=json
```

## 응답에서 쓸 항목

| 항목 | 뜻 | 화면 |
|---|---|---|
| `routeno` | 노선번호 | 카드 제목 |
| `routetp` | 노선유형 (마을버스 등) | 작은 글씨 |
| `arrtime` | 도착 예상 시간 (초) | "n분 n초" |
| `arrprevstationcnt` | 남은 정류장 수 | "n정류장 전" |
| `vehicletp` | 차량유형 (저상버스 등) | 표시 |
| `nodenm` | 정류소명 | 화면 위 제목 |

## 막히는 곳

- 정류소 ID는 이 API로 찾을 수 없다. 별도 API(TAGO 버스정류소정보)를 또 신청해야 해서 강사가 미리 뽑아 준다.
- 도착 버스가 1대면 `item` 이 목록이 아니라 하나로, 0대면 `items` 가 빈 값으로 올 수 있다. "항상 목록으로 바꿔서 쓰라"고 시킨다.
- 서울 시내버스가 TAGO에 들어 있는지는 리허설에서 확인한다 (서울시는 버스도착정보를 따로 제공한다).
- 스냅샷은 받은 시각의 값이다. 화면에 "예시 데이터"라고 적어 둔다.

## 향후 고도화 (교육 시간 밖 — 기록만)

- 정류소 이름으로 검색 — TAGO 버스정류소정보 API 추가 신청
- 내 위치 근처 정류소 — 위치 권한 · 좌표 기반 조회
- 30초마다 자동 새로고침, 즐겨찾는 정류소 저장
- 특정 노선만 보기 — "정류소별특정노선버스 도착예정정보" 기능
