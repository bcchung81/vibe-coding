# 약 설명서 쉽게

> 건강 · 식약처 e약은요 · 난이도 하

| 항목 | 내용 |
|---|---|
| 만드는 것 | 약 이름을 검색하면 효능 · 먹는 법 · 주의사항 · 보관법을 큰 글씨 카드로 보여 주는 한 화면 |
| API | [식품의약품안전처_의약품개요정보(e약은요)](https://www.data.go.kr/data/15075057/openapi.do) |
| 승인 · 한도 | 개발계정 자동승인 · 하루 10,000회 |
| 응답 형식 | JSON (`type=json`, 빼면 XML) |
| 강사가 미리 주는 것 | `snapshot.json` |

이 파일이 **주제 카드**다. 시작 폴더(`vibe.zip`)의 `topics\` 에도 들어 있다. 1일차 2교시 첫 명령은 `/vibe-prd 05` — 에이전트가 이 카드를 읽고 인터뷰를 시작한다.

## 교육 시간 안에 만드는 것

| 언제 | 할 일 |
|---|---|
| 1일차 3교시 (화면 30분) | 검색창 → `snapshot.json` 에서 약을 찾아 항목별 카드로 보여 주기, 화면 아래 안내 문구 고정 |
| 1일차 3교시 (실제 API 20분) | `/api/data` 라우트가 스냅샷 대신 실제 API를 검색어로 부르게 바꾸기 |

완료 기준 예시

- "타이레놀"을 검색하면 효능 · 먹는 법 · 주의사항 · 보관법이 제목과 함께 나뉘어 보인다
- 화면 아래에 "의료 조언이 아닙니다. 복용 전 약사 · 의사와 상담하세요"가 늘 보인다
- 본문에 `<p>` 같은 태그 글자가 보이지 않는다

## 키 넣기

| 어디에 | 어떤 키 |
|---|---|
| 브라우저 주소창으로 시험할 때 | **Encoding** 키 |
| `.env.local` · Vercel 환경변수 | **Decoding** 키 — 코드가 다시 인코딩한다. Encoding 키를 넣으면 이중 인코딩되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |

- 자동승인이어도 키 반영에 1~2시간 걸릴 수 있다. 교육 전에 아래 시험 URL로 `resultCode` `00` 을 확인한다.
- 키 값은 에이전트에게 말하지 않는다. 본인이 `.env.local` 에 직접 넣는다.

## API 요청

요청 주소

```
https://apis.data.go.kr/1471000/DrbEasyDrugInfoService/getDrbEasyDrugList
```

| 파라미터 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `ServiceKey` | ● | 내 키 | 이 API는 대문자 S |
| `itemName` | | `타이레놀` | 제품명 (검색어) |
| `type` | | `json` | |
| `numOfRows` | | `10` | |
| `pageNo` | | `1` | |
| `entpName` | | | 업체명으로 찾기 |

시험 URL (브라우저, Encoding 키)

```
https://apis.data.go.kr/1471000/DrbEasyDrugInfoService/getDrbEasyDrugList?ServiceKey=내_Encoding_키&itemName=타이레놀&type=json&numOfRows=10&pageNo=1
```

## 응답에서 쓸 항목

| 항목 | 뜻 | 화면 |
|---|---|---|
| `itemName` | 제품명 | 카드 제목 |
| `entpName` | 업체명 | 작은 글씨 |
| `efcyQesitm` | 효능 | "어디에 먹나요" |
| `useMethodQesitm` | 사용법 | "어떻게 먹나요" |
| `atpnWarnQesitm` · `atpnQesitm` | 주의사항 (경고 · 일반) | "조심할 점" |
| `intrcQesitm` | 상호작용 | "같이 먹으면 안 되는 것" |
| `seQesitm` | 부작용 | "이상 반응" |
| `depositMethodQesitm` | 보관법 | "보관" |
| `itemImage` | 낱알 이미지 | 사진 (없으면 빈 자리) |

## 막히는 곳

- 일반의약품 중 공급실적이 있는 약만 있다. 전문의약품은 나오지 않는다 — 결과가 없을 때 이 점을 안내한다.
- 본문에 `<p>` 같은 HTML 태그가 섞여 올 수 있다. 태그를 지우고 **글자로만** 보여 주게 시킨다 (HTML을 그대로 화면에 넣지 않는다).
- 이미지가 없는 약이 많다. 사진 칸이 비어도 화면이 깨지지 않게 한다.
- 의료 정보라 "의료 조언이 아님" 문구를 빼지 않는다.

## 향후 고도화 (교육 시간 밖 — 기록만)

- 여러 약을 같이 먹어도 되는지 비교
- 모양 · 색으로 낱알 찾기 — 의약품 낱알식별(별도 API)
- 복약 시간 알림
- 큰 글씨 · 소리로 읽어 주기
