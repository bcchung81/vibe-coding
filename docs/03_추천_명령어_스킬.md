# 추천 명령어 · 스킬 — 기본 제공이 아닌 것

> 강사 PC(macOS)에 설치된 커스텀 명령 · 스킬 · 플러그인 가운데 교육에 쓸 것을 골랐다. 2026-10-21 확인.
> 수강생 PC 설치는 교육 전에 `setup.ps1` 하나가 1 · 2일차 것을 모두 한다(보고서 스킬 kca-report-hwpx 포함). ego lite만 수강생이 직접 설치한다. 교육 중에는 새로 설치하지 않는다.

**고르는 기준**
1. Codex에서 스킬로 돈다.
2. 교육에서 받은 ChatGPT 계정 하나로 된다. 다른 구독이나 유료 API 키가 필요 없다.
3. Windows · PowerShell에서 돈다.
4. 구독 사용량 부담이 작다. 하위 에이전트를 여럿 돌리거나 high effort를 쓰지 않는다.
5. 비개발자가 결과를 보고 판단할 수 있다.

## 커스텀 명령은 파일 하나다 (1일차 2교시 · 2일차 3 · 4교시)

자주 쓰는 지시를 매번 치는 대신 파일로 둔다. `think` 는 15줄짜리 지시문 한 장이다. Codex에서는 **스킬** 로 만든다.

| 만드는 곳 | 확인 | 부르는 법 |
|---|---|---|
| 전역 `~\.agents\skills\이름\SKILL.md` · 프로젝트 `.agents\skills\이름\SKILL.md` | `/skills` | `이름 스킬로 ~해줘` (예: `vibe-plan 스킬로 주제 02 시작해줘`) |

- `setup.ps1` 이 `think` 를 전역 폴더에 이렇게 설치한다.

## A-2. 시작 폴더 명령 — `vibe.zip` 에 들어 있다 (설치 없음)

1일차 2교시에 `C:\workspace\vibe` 로 푸는 시작 폴더(원본 `docs/교육생_배포/vibe/`)의 프로젝트 명령. 교안의 프롬프트를 명령으로 묶었다. `.agents\skills` 에 있고, "vibe 명령을 전역에도 설치해줘" 하면 Codex가 전역 스킬 폴더(`~\.agents\skills`)로 복사한다.

| 이름 | 하는 일 | 불러 쓰는 전역 스킬 | 쓰는 교시 |
|---|---|---|---|
| vibe-plan | 주제 카드로 질문 5개 이하 인터뷰 → `PRD.md` → `PLAN.md`(화면 4단계 이하 + 실제 API 단계, 단계마다 완료 기준). 코드는 고치지 않는다 | think (범위가 막힐 때) | 1일차 2교시 (이틀 참여자는 2일차 1교시 고도화 단계 추가에도) |
| vibe-develop | 상황에 따라 하나: ① 안 끝난 첫 단계 하나 구현 → 빌드 · ego-browser로 완료 기준 눌러 보기 ② 오류 원문 → 원인 가설 3개 · 확인 방법 → 하나씩 고치기 ③ 배포 전 점검 3가지(키가 git에 없나 · 키 없이 빌드되나 · 오류 원문이 안 보이나) ④ 완료 기준 전부 다시 점검 | think (원인이 안 보일 때) · ego-browser (눌러 보기) | 1일차 3 · 4교시, 막혔을 때 |

- 이름에 `vibe-` 를 붙인 이유: Codex 기본 스킬 `plan` 등과 겹치지 않게 하고, `/skills` 목록에서 세 개가 함께 모이게 했다.
- 5개(vibe-prd · plan · step · fix · check)에서 3개로 줄였다 (2026-11-05). 수업 순서는 plan → develop → design → develop(배포 전 점검).
