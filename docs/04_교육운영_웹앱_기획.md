## 1. 목적 → 기능

| 목적 | 기능 | 화면 |
|---|---|---|
| ① 교육 안내 | 일시 · 장소 · 사전 준비 회신 · 문의(관리 화면에서 적음 — 문의처를 공개 저장소에 두지 않으려고 DB에 둔다), 이틀 구성(`docs/00_전체목차.md` 의 표를 그대로 읽음), 미리 준비할 것(`00_사전안내.md` 2장 표를 읽어 1일차만 · 2일차만 · 이틀 모두로 거름 · 체크는 이 브라우저에만) | `/course` (첫 화면 `/` 가 여기로 간다) |
| ① 자료 배포 | `docs/교육생_배포/` 문서 읽기 · 내려받기. 열어 본 자료는 이 브라우저에 기억해 완료 · 다음 · 아직으로 보여 준다 | `/materials` · `/materials/[단계]/[이름]` |
| ② 1일차 시작 폴더 | 웹앱 주제 3가지 중 하나를 "내 주제"로 고르면(이 브라우저에만 기억) 주제 자료가 열리고, `vibe.zip`(규칙 · vibe 명령 3개 · 주제 카드 · 주제별 예시 데이터 · Next.js 뼈대)을 `C:\workspace\vibe` 에 푸는 PowerShell 한 줄을 준다 | `/topics` · `/topics/[번호]` · `/vibe.zip` |
| ② 2일차 시작 폴더 | 자료 화면 맨 아래에서 `deck.zip`(덱 틀 · 3D 장면 3개 · deck 명령 3개 · 영상 만들기)을 `C:\workspace\deck` 에 푸는 한 줄을 준다 | `/materials` · `/deck.zip` |
| ③ 발표 | 수업 발표 덱(`docs/발표자료/발표.html`)을 그대로 보여 준다. 허브 틀 밖의 한 페이지 — 1 · 2일차 고르기, `#d1-10` 처럼 날 · 장 번호 주소, → · ← · F 키. 글꼴과 OFL 고지를 함께 내보낸다(`lib/slides.ts`) | `/slides` · `/slides/slides.css` 등 (2026-11-07) |
| 운영 | 관리 PIN → 교육 안내 입력 · 남은 데이터 지우기(예전 명단 · 수요조사 응답 · PIN 기록) | `/admin` |

## 3. 화면 구성 (`app/`)

| 경로 | 내용 | 볼 수 있는 사람 |
|---|---|---|
| `/` | `/course` 로 넘긴다(`next.config.ts`) | 누구나 |
| `/course` | 교육 안내 — 일시 · 장소 · 회신 · 문의, 1 · 2일차 교시표, 참여 유형별로 남는 것, 미리 준비할 것 체크리스트 | 누구나 |
| `/materials` · `/materials/[단계]/[이름]` | 자료 목록(단계별, 완료 · 다음 · 아직) · 문서 읽기 · 내려받기 · 2일차 덱 시작 폴더 | 누구나 |
| `/topics` · `/topics/[번호]` | 웹앱 주제 3가지 · 내 주제 고르기 · 주제 자료 · 주제 카드 내려받기 · 시작 폴더 | 누구나 |
| `/vibe.zip` · `/deck.zip` | 시작 폴더 (빌드 때 `docs/교육생_배포/vibe` · `deck` 에서 만든다) | 누구나 |
| `/slides` | 발표 덱 (빌드 때 `docs/발표자료` 에서 읽는다 — 원본은 그 폴더 하나) | 누구나 |
| `/admin` | 관리 PIN 4칸 → 교육 안내 입력 · 남은 데이터 지우기 | 관리자 |
| `/api/session` | 관리자인지 — 상단 메뉴의 '관리'만 쓴다. 저장하지 않음(`no-store`) | 본인 |

상단 메뉴: 교육 안내 · 자료 · 웹앱 주제 · 발표(덱 페이지로 바로 간다), 관리자에게만 '관리'와 오른쪽 끝 '관리자 로그아웃'.

## 4. 권한

- **공개 범위:** 관리 화면 말고는 누구나 본다. 수강생 로그인은 없다.
- **관리자(강사 · 조교):** 관리 PIN 4자리(`ADMIN_PASSWORD`). 같은 곳(IP)에서 10분에 10번, 모든 곳 합쳐 1시간에 50번 틀리면 막는다(`lib/pin-limit.ts`). 누가 일부러 막히게 하면 Vercel에서 값을 바꾸고 다시 배포한다.
- **세션:** `SESSION_SECRET` 으로 서명한 쿠키(`lib/session.ts`). `/admin` 페이지와 저장하는 서버 함수(`app/actions.ts`)가 쿠키 · PIN을 각자 확인한다. 메뉴를 숨기는 것은 보기 편하게 하려는 것이다.

## 5. 데이터

| 표 | 내용 |
|---|---|
| `course_info` | 교육 안내 맨 위의 일시 · 장소 · 사전 준비 회신 · 문의. 한 줄뿐이고 관리 화면에서 고친다 |
| `pin_failures` | 틀린 관리 PIN의 IP · 시각. 하루 지나면 지운다 |
| `students` · `projects` · `likes` · `survey_answers` | 뺀 학생 로그인 · 갤러리 · 수요조사의 표. 남은 데이터를 지우지 않으려고 표만 두고, 관리 화면 '모두 지우기'가 지운다 (2026-11-07 기준 수강생 16명 · 응답 1건이 남아 있다) |

- 표 정의: `db/schema.sql`. DB 질의는 `lib/db.ts`. 교육 안내 표 읽기 · 입력 검사는 `lib/course.ts`(실제 문서로 테스트). 표 만들기: `vercel env pull .env.local` → `npm run db:setup`.
- 이 저장소는 공개다. 실제 데이터는 DB에만 둔다.

## 6. 배포 · 연결

- Vercel 프로젝트 `vibe-coding-hub` 에 이 폴더를 연결했다 (2026-10-24). 배포는 CLI `vercel deploy --prod` 로 한다. GitHub 자동배포는 켜지 않았다.
- Neon(`kca-vibe-db`)을 쓴다. Blob(`kca-vibe-captures`)은 첫 화면 캡처를 뺀 뒤 쓰지 않는다 — 비어 있다 (2026-11-07 확인).
- 환경변수는 `.env.example` 의 이름 그대로 Vercel에 넣는다. 뺀 기능의 `COURSE_PIN` · `BLOB_READ_WRITE_TOKEN` 은 Vercel에 남아 있어도 쓰지 않는다.
