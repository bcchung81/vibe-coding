# 바이브코딩 중급교육

> **바이브코딩**은 코드를 직접 짜는 대신 AI에게 말로 설명해서 프로그램을 만드는 방법입니다.
> 1일차에는 기관 업무 데이터로 작은 웹앱을 만들어 인터넷에 공개하고, 2일차에는 한 주제로 보고서 · 3D 발표자료 · 영상을 만듭니다.
> **하루만 들어도 됩니다.** 두 날은 따로 완결됩니다.

## 날마다 손에 쥐는 것

| 날 | 손에 쥐는 것 |
|---|---|
| 1일차 | **내가 만든 기관 업무 웹앱** — 공공데이터를 불러와 보여 주는 작은 프로그램 · **인터넷 주소** — 누구나 휴대폰으로 열어 볼 수 있습니다 |
| 2일차 | **1쪽 보고서(hwpx)와 내 규칙** — 조건을 규칙으로 넣어 AI의 보고서를 바꿔 봅니다 · **3D 발표자료(HTML)** · **30초 영상(mp4)** |

| 준비물 | Windows 11 노트북(인터넷망, 외장 그래픽카드 없어도 됩니다). Codex(ChatGPT) 계정은 기관이 지원해 교육 당일 드립니다 |

| 일시·장소 | 확정 후 안내 |

교시 사이에 쉽니다. 교시마다 처음에 그 시간에 쓰는 도구가 어떻게 이어지는지 그림으로 설명합니다.

| 시간 | 하는 일 |
|---|---|
| 13:30–14:15 | 로그인 · 점검 → 오늘 쓰는 도구 지도 → 시작 폴더 받기 → AI 브라우저로 공공데이터 API 설명 읽기 |

| 16:30–17:00 | 인터넷에 공개하기 (Vercel) · 휴대폰으로 서로 열어 보기 |

| 13:30–14:30 | 보고서 ② — 지적을 규칙으로 올려 한글 파일(hwpx)로 → AI가 화면에서 열어 확인하는 것 보기(computer use, 강사 시연) → 발표 HTML과 3D의 구조 · 예시 덱 띄워 보기 |

## 이렇게 배웁니다

- **AI에게 일 잘 시키기** — 무엇을, 어떤 순서로, 어디까지 하면 끝인지 먼저 정하고 맡깁니다.
- **도구 구조 알기** — 규칙 파일 · 스킬(절차서) · MCP(외부 연결) · 명령 도구 · AI 브라우저 · computer use가 각각 무엇이고 언제 쓰는지 그림으로 봅니다.
- **도구 고르는 순서** — 명령 · API로 되면 그것으로, 웹 화면을 봐야 하면 브라우저로, 브라우저 밖 프로그램이면 computer use로.
- **공공데이터 활용** (1일차) — 공공데이터포털의 기관 데이터를 내 웹앱에 붙여 인터넷에 공개합니다.
- **하네스를 내 규칙으로** (2일차) — 같은 지적을 두 번 하지 않게, 조건을 규칙 파일로 남깁니다.
- **3D 발표와 영상** (2일차) — 그래픽카드가 없는 노트북에서도 돌아가게 만듭니다.

우리 동네 라디오 주파수 · 자격시험 일정 · 가까운 시험장 찾기 · 생활 전자파 확인 · 무선국 검사 현황판 · 기금사업 찾기
