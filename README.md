# 바이브코딩 중급교육

> **바이브코딩**은 코드를 직접 짜는 대신 AI에게 말로 설명해서 프로그램을 만드는 방법입니다.
> 이 교육에서는 이틀 동안 AI와 함께 생활·업무에 쓸 작은 웹앱을 만들고, 인터넷에 공개하고, 소개 영상까지 만듭니다.

## 이틀 뒤에 손에 쥐는 것

1. **내가 만든 웹앱** — 공공데이터를 불러와 보여 주는 작은 프로그램
2. **내 웹앱의 인터넷 주소** — 누구나 휴대폰으로 열어 볼 수 있습니다
3. **30~45초 소개 영상** — 내 웹앱을 보여 주는 짧은 영상
4. **보고서 초안 1건** — 공개자료를 근거로 만든 한글(hwpx) 문서

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 대상 | 에이전틱 AI 기초(초급) 과정을 마친 분 30명 |
| 기간 | 2일, 총 8시간 30분 (휴식 포함) |
| 준비물 | Windows 11 노트북(인터넷망), AI 코딩 도우미 구독 1개 (월 약 $20부터) |
| AI 코딩 도우미 | Codex · Claude Code · Antigravity 중 하나를 골라 본인 계정으로 사용 |
| 일시·장소 | 확정 후 안내 |

## 일정

교시 사이에 10분씩 쉽니다.

### 1일차 — 갖추고, 만든다 (13:30~17:00)

| 시간 | 하는 일 |
|---|---|
| 13:30–14:15 | 내 노트북에 AI 작업환경 갖추기 — 설치 스크립트 한 번으로 점검·로그인 |
| 14:25–15:05 | 작은 업무를 AI에게 시켜 보기 |
| 15:15–16:45 | 내 웹앱 만들기 — 기획 → 화면 디자인 → 기능 붙이기 |
| 16:45–17:00 | 만든 결과를 GitHub(코드 보관소)에 올리기 |

### 2일차 — 연결하고, 공개하고, 보여 준다 (09:30~11:00 · 13:30~17:00)

| 시간 | 하는 일 |
|---|---|
| 09:30–10:15 | 내 웹앱에 공공데이터 연결하기 |
| 10:25–11:00 | 내 웹앱을 인터넷에 공개하기 (Vercel) |
| 13:30–14:40 | 내 웹앱 소개 영상 만들기 |
| 14:50–16:20 | 공개자료로 기관 양식 보고서 만들기 |
| 16:30–17:00 | 상영회 · 수료 |

## 이렇게 배웁니다

- **AI에게 일 잘 시키기** — 무엇을, 어떤 순서로, 어디까지 하면 끝인지 먼저 정하고 맡깁니다.
- **AI에게 규칙과 도구 쥐여 주기** — 지침 파일, 반복 업무 절차(스킬), 외부 도구 연결(MCP)을 필요할 때 골라 씁니다.
- **공공데이터 활용** — 공공데이터포털의 무료 데이터를 내 웹앱에 붙입니다.
- **만들고 끝내지 않기** — 인터넷 공개, 소개 영상, 상영회까지 갑니다.
- **보고서에도 쓰기** — 공개자료에서 근거를 붙여 기관 양식 보고서 초안을 씁니다.

## 만들어 볼 웹앱 예시

생활에 바로 쓰는 공공데이터 주제 가운데 하나를 고릅니다. 최종 주제는 확정 후 안내합니다.

버스 도착 시간 · 우산 챙길까(날씨) · 미세먼지 확인 · 음식 칼로리 찾기 · 상비약 설명서 · 밤에 여는 소아과 · 유기동물 입양 · 이번 주말 축제 · 우리 동네 아파트 실거래가 · 장바구니 물가
