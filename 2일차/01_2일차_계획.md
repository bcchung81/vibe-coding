## 1교시 · 외부 MCP 연결 (09:30–10:40)

**목표**: MCP가 어디에 설치되고 어떻게 연결되는지 이해한다. 업무용 MCP를 직접 붙여 쓴다.

| 시간 | 진행 |
|---|---|
| 09:30–09:50 | 강의 — MCP 구조 · 설치 범위 · 보안 |
| 09:50–10:30 | 실습 — 법령 · 한글문서 MCP (+ 선택 2종) |
| 10:30–10:40 | 정리 — `/mcp` · `claude mcp list` 로 상태 읽기 |

### 강의 (20분)

**설치 범위 3종** — 실례는 강사 PC

| 범위 | 위치 | 누가 쓰나 | 실례 |
|---|---|---|---|
| user | `~/.claude.json` | 내 PC의 모든 폴더 | sequential-thinking · kordoc · 법령 · 엑셀 · GitHub 등 7종 |
| project | 프로젝트의 `.mcp.json` | 그 저장소를 여는 모든 사람 | 문서처리 앱 프로젝트(shadcn · playwright 등), 경영평가 프로젝트(Notion 원격) |
| plugin | 플러그인에 번들 | 플러그인 설치자 | report-harness가 kordoc · 법령 MCP를 함께 가져옴 |

**연결 방식 2종**
- **stdio**: 내 PC에서 프로그램을 띄운다 (`npx` · `uvx`). 실행기(Node · Python uv)가 PC에 있어야 한다.
- **http**: 원격 서버에 붙는다 (예: Notion). OAuth로 로그인한다.

**보안 수칙 4가지**
1. 출처를 확인한다 (누가 만들었나, 저장소·라이선스).
2. 토큰을 설정파일에 직접 적지 않는다 — 환경변수나 OAuth를 쓴다.
3. 읽기 전용 도구부터 붙인다.
4. 프로젝트 범위 MCP는 저장소를 연 사람 모두에게 퍼진다는 점을 기억한다.

### 실습 (40분)

**① 법령 MCP — 필수**

먼저 사전과제에서 받은 법제처 Open API 인증값을 환경변수로 저장한다. 2교시 report-harness도 이 값을 쓴다.
- Windows: `setx LAW_OC "본인값"` + `$env:LAW_OC = "본인값"`
- macOS: `echo 'export LAW_OC="본인값"' >> ~/.zshrc && source ~/.zshrc`

등록:
```bash
# macOS
claude mcp add --scope user -e LAW_OC="$LAW_OC" korean-law -- npx -y korean-law-mcp
# Windows (Git Bash)
MSYS_NO_PATHCONV=1 claude mcp add --scope user -e LAW_OC="$LAW_OC" korean-law -- cmd /c npx -y korean-law-mcp
```
재시작 후 시험: `전파법에서 무선국 개설 허가 관련 조문을 찾아 요약하고 조문 번호를 붙여줘`

**② 한글문서 MCP(kordoc) — 필수 (1일차에 설치됨)**

`샘플.hwpx 의 표를 모두 뽑아 표마다 한 줄 요약을 붙여 tables.md로 정리해줘`

**③ Notion (원격 http) — 선택, 기관 Notion 계정이 있는 사람**
```bash
claude mcp add --transport http --scope user notion https://mcp.notion.com/mcp
```
`/mcp` 에서 notion을 골라 브라우저로 인증한다.

**④ 엑셀 MCP — 선택**

Python 실행기 `uv` 가 필요하다 (stdio 실행기 차이를 보여 주는 예).
- Windows: `winget install --id astral-sh.uv -e`
- macOS: `brew install uv`

```bash
claude mcp add --scope user excel -- uvx excel-mcp-server stdio
```

### 정리 (10분)

- `claude mcp list` 결과에서 `✓ Connected` / `✗ Failed` 를 읽는 법
- 실패 원인 세 가지: 실행기 없음 · 환경변수 없음 · Windows 경로 변환

**강사 준비물**: 강사 PC의 MCP 범위별 실례 화면 · 표가 많은 샘플 hwpx · `LAW_OC` 미발급자용 강사 시연

## 3교시 · MCP vs 운영 런타임 (13:00–13:50)

**목표**: 개발할 때 쓰는 연결(MCP)과 운영 앱이 쓰는 연결(직접 API)이 왜 다른지 이해한다.

| 시간 | 진행 |
|---|---|
| 13:00–13:25 | 강의 — 같은 법령 기능, 두 가지 구현 |
| 13:25–13:50 | 실습 — 내 앱의 외부 호출 구조표 |

### 강의 (25분)

**핵심 문장**: MCP는 개발·업무 단계에서 **에이전트의 손발** 이다. 운영 앱은 **직접 API를 부르고 가드를 둔다**.

| 구분 | 개발 · 업무 (에이전트) | 운영 앱 (서비스) |
|---|---|---|
| 법령 조회 | 법령 MCP — 에이전트가 필요할 때 부름 | 법제처 Open API 직접 호출 + 응답 캐시 + 인용 검증 (규정·법령 어드바이저) |
| 호출 주체 | 사람 옆의 에이전트 1명 | 불특정 다수 사용자 |
| 실패 시 | 에이전트가 다시 시도·우회 | 사용자 화면에 정돈된 오류, 비용·횟수 가드 |

- **근거**: 강사가 운영 중인 서비스 6개의 소스를 검색했더니, 런타임에서 MCP를 쓰는 곳은 **0건** 이었다.
- **에이전트로 배포 다루기**: `gh` · `vercel` CLI(또는 Vercel MCP)로 저장소·배포·환경변수를 에이전트가 다룬다. 5교시에 쓴다.

### 실습 (25분)

```
내 앱 코드에서 외부로 나가는 호출을 전부 찾아 표로 정리해줘.
열: 호출 위치(파일:줄) · 대상 · 쓰는 키 이름 · 서버/브라우저 중 어디서 실행되나 · 실패하면 사용자에게 뭐가 보이나
```

**확인**: "브라우저에서 실행" 칸에 키가 있으면 4교시 기준 ①에 걸린다.

### 기준 10개

| # | 기준 | 근거 사례 (운영 서비스) | 내 앱 확인 질문 |

| 7 | 오류 원문을 숨기고 로그를 구조화한다 | 규정·법령 어드바이저(원문은 서버 로그에만) · 경영평가 Sherpa(오류 번호 한 줄 로그, AI 호출 기록에 본문 미저장) | 오류 화면에 스택·키·쿼리가 보이나? |
| 8 | 보안 강화 설정도 검증한 뒤 배포한다 | 규정·법령 어드바이저 — 강화한 보안 헤더(CSP)가 운영 전면 장애를 내서 호환형으로 교체 | 헤더를 바꾼 뒤 프리뷰에서 전 화면을 열어 봤나? |
| 9 | LLM 특화 위험을 막는다 — 프롬프트 인젝션 · SSRF. 공식 숫자는 LLM을 거치지 않게 한다 | 성과돋보기 — 공공데이터 숫자는 LLM 없이 원천에서 바로 넣음 | 사용자가 넣은 URL·문장을 그대로 실행·호출하나? |
| 10 | 자동 추정 결과는 사람이 확인하기 전 공식 기록으로 쓰지 않는다 | 국정감사 화자 표기 — 화자·금액은 추정이라 공식 기록 사용 금지 고지 | 화면에 "AI 추정" 표시와 이용 고지가 있나? |

### 기관 거버넌스와 연결 (10분)

- **원칙**: "개발의 자유는 넓게, 운영의 책임은 분명하게"

**강사 준비물**: 사례 슬라이드(서비스 이름만 쓰고 팀·프로젝트 ID · 도메인 · 키 이름은 지운 판) · 퀴즈 5문항

### ② 필수 수정 (이 4개는 반드시)

| 기준 | 할 일 |
|---|---|
| ① | `.env.local` 이 `.gitignore` 에 있나 · `.env.example` 추가 · 키에 `NEXT_PUBLIC_` 없음 |
| ② | 키 없이 `npm run build` 통과 |
| ④ | 서버 라우트에 간단한 횟수 제한 (IP당 분당 N회) |
